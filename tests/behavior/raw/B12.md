# B12 — 只有 DSers 工具，用户要求“把 IMP-DEMO-01 直接上架到 TikTok Shop”

## 助手回复

这一步我不能用现在的工具替你直接上架到 TikTok Shop，先说明原因，再给你能马上用的东西。

**为什么不能直接推**
- 当前会话里只连了 DSers（店铺是 Shopify/Wix）。DSers 推送工具里虽然有 `sales_channel = tiktok` 这个选项，但它不是 TikTok Shop 原生商品发布，用它推送不能算“上架到你的 TikTok Shop”，结果也无法在 TikTok Shop 后台回读验收。
- 本 Skill 目前没有 TikTok Shop 原生发布适配器，所以发布动作记为：**未执行——缺少 TikTok Shop 原生发布适配**。

**我现在能做的：TikTok 上架资料包（草案）**

基于 IMP-DEMO-01 的已有商品事实，我会按 SKU 整理以下内容，交给你在 Seller Center 里自己发布：

| 部分 | 当前状态 |
|---|---|
| 基本信息（市场、TikTok 店铺 ID、语言、币种、事实版本） | 待补：你的 TikTok Shop 是哪个市场/店铺？ |
| 类目与品牌 | 按后台规则建议，不选相似类目规避资质 |
| 标题 / 详情 | 按商品事实改写，没证据的卖点列为缺口 |
| 图片与视频 | 去掉供应商水印和其他平台标识 |
| 属性、变体/SKU | 与成本、重量、库存一一对应 |
| 价格（日常价 / 活动最低价 / 保本价） | 按共用利润口径；成本未知就写未知 |
| 库存、物流（包装后重量、三边尺寸、发货时效） | 需样品实测，不填虚假库存 |
| 售后、合规资料 | 资料不齐不发布 |
| ID 映射 | IMP-DEMO-01（DSers）↔ TikTok 商品/SKU 待你发布后回填 |

发布前请按商品上线顺序走：拿样验品 → 复核利润 → 做商品卡 → 设置库存与物流 → 发布后前台验收。

**需要你回答的 1 个问题**：你的 TikTok Shop 是哪个市场（例如美国/东南亚某国）、店铺 ID 是什么？确定后我把资料包按该市场的语言和币种出成完整版。你在 Seller Center 发布后，把后台状态截图（打码）发我，我再帮你记录“审核中/已上线/被拒”和前台验收。
