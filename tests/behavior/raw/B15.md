**审阅单补充项**

| 项 | 内容 |
|---|---|
| 对象 | IMP-DEMO-01 → Shopify 店铺（以审阅表中的店铺 ID 为准） |
| 已批准 | 标题、价格按审阅表；可见性按审阅表 |
| 新增副作用 | 物流配置 “US Standard”：当前 = 关闭 → 推送后 = 启用（账户级） |
| 需要你决定 | 是否允许这次推送同时启用 “US Standard” |

**你可以选**
- **A. 允许**：我按审阅表推送，并记录 “US Standard” 推送前后的值和时间，推送后回读商品和物流配置。

请回复 A 或 B。你选 A 之前，我不会推送。
