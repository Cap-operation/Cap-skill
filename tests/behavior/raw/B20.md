# B20 — 不同口径的 ROAS/ROI 比较 + 挪预算

## 助手回复

结论先说：**现有数据不能说明 B 比 A 赚钱多**，所以我先不挪预算。原因有三：

| | Campaign A | GMV Max B |
|---|---|---|
| 指标 | 普通广告 ROAS 3.2 | GMV Max ROI 4.0 |
| 币种 / 时区 | USD / America/Los_Angeles | GBP / Europe/London |
| 归因 | 7 天点击 | 未注明（可能 1 天点击，待核实） |
| 收入范围 | 广告归因收入 | GMV Max 的 ROI 通常包含部分自然流量等贡献，不是纯付费效果 |

1. **口径不同**：币种、时区、归因窗口都不一样，B 的 ROI 还把一部分自然成交算了进去，3.2 和 4.0 不能直接比大小。
2. **没有成本和退款**：ROAS/ROI 是收入除以广告费，不是利润。没有采购、物流、平台费、退款，就不能说谁“赚钱”。
3. **“挪预算”不是一个动作**：A（USD 账户普通广告）降预算、B（GBP 的 GMV Max）加预算是两笔独立写入，币种不同不能直接搬，给 B 加预算会增加 GBP 的实际花费。

我建议的做法：

- 先补数据：B 的归因口径和 ROI 定义；两边同一时间段的**订单成本和退款**。我用统一的贡献利润口径分别算 A、B 每花 1 块钱带来的利润，再判断。
- 如果你仍想现在就调，请给我具体数字，例如：“A 日预算从 __ USD 降到 __ USD；B 日预算从 __ GBP 升到 __ GBP，观察 __ 天，B 的 ROI 低于 __ 就恢复”。我会先读两边最新预算，按这个做成变更表给你看，确认后再执行并回读。

本次只读分析，A 和 B 都没有改动。
