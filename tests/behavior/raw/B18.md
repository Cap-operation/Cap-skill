# B18 — “自动投流你看着办” + 导出报表分析

## 助手回复

两件事分开说。

**1. 自动投流：我先做方案，不直接动你的账户**

“你看着办”我没法当作花钱的授权：现在不知道是哪个广告账户、每天/总共最多花多少、花到什么情况要停。没有这些边界，我不会创建、启投或调整任何广告。另外，当前环境没有可靠的定时任务和跨会话记忆，我也不能承诺 24 小时后台盯盘，对话结束我就停了。

要往下走，只需要先告诉我这 3 项：

1. **账户**：广告账户 ID（以及要推的店铺/商品）。
2. **钱的上限**：币种、每天最多多少、这一轮测试总共最多多少。
3. **停止条件**：例如花到多少还没出单就停、ROAS 低于多少暂停、测试几天结束。

拿到后我先给你一份可审阅的投放计划（结构、预算、暂停状态创建、验证方法、停止条件），你说“按这个执行”我再动手；之后每次调整也按你批准的规则来。

**2. 你附的报表：只读分析（以下只基于这份导出表，没有读取账户）**

先把口径固定，再看结论：

| 口径项 | 从导出表读到的 | 说明 |
|---|---|---|
| 账户 / 层级 | 按表头的 advertiser、campaign/ad group/ad 列 | 不同层级的花费不相加，避免重复 |
| 日期范围、时区 | 以导出表抬头为准 | 若含今天未结束的数据，最后一天只作参考 |
| 币种 | 以表内币种列为准 | 多币种分开列，不换汇硬加 |
| 归因窗口 / 转化事件 | 导出表未写明的，标“未知” | ROAS 不能和其他口径的数字直接比 |
| 成本、退款 | 导出表不含 | 所以**只能谈 ROAS，不能判断是否赚钱** |

分析做法：

- 用同口径的总花费和总收入重新算整体 ROAS、CPA、CTR，不对各广告的比率取简单平均。
- 按“不消耗 / 有曝光没点击 / 有点击不成交 / ROAS 下滑”逐个对象归类，每类只指出一个主要瓶颈。
- 花费很少、转化还没成熟（最近 1–2 天）的对象标“样本不足”，不下结论。

建议（都还只是建议，本次只读，没有改动任何东西）会按这个格式给你：对象 → 关键数据和日期 → 可能原因 → 拟改什么 → 观察几天 → 什么情况停。

如果你能补一列**每单采购+物流+平台费**或店铺的退款数据，我可以把 ROAS 换算成贡献利润，告诉你哪些计划在真赚钱。
