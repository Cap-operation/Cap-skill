**先说清楚一个前提**：GMV 和 ROAS 不是利润。没有采购、物流、平台佣金、优惠和退款数据，我没法判断哪条计划在赚钱，只能按"相对表现 + 证据缺口"给建议。拿到成本后可以算保本 ROAS：保本 ROAS = 1 ÷（未计广告时的单件贡献利润 ÷ 成交价）。ROAS 低于这条线才算亏，高于这条线也还要扣掉实际退款。

**建议（待你确认后自己在后台操作，我这边没有执行）**

1. **C3：优先考虑暂停或先排查**
   - 证据：花费 50 USD，7 天点击归因 GMV 为 0。
   - 先看：这段时间有没有点击。有点击没成交，问题多半在商品卡、价格、运费或库存，先修转化路径，不要直接加预算。基本没点击，先看素材和商品是否匹配。
   - 注意：如果计划刚建、刚改过预算，或者日期范围包含最近几天，7 天点击归因还可能回填成交，现在的 0 不一定是最终结果。
   - 停止条件：数据成熟后仍然 0 成交，就暂停。

2. **C2：保留观察，暂不加预算**
   - 证据：ROAS 1.13，每花 1 美元只带回约 1.13 美元归因 GMV。按电商常见的成本结构，这很可能低于保本线，但缺成本数据，还不能下结论。
   - 拟改：拿到成本、算出保本 ROAS 之后，如果 C2 仍低于保本线，就降预算或换一个素材/卖点做测试，每次只改一个变量。
   - 观察窗口：按你自己的规则定，至少等转化数据成熟再判断，不要按小时级波动反复改。

3. **C1：维持现状，不急着放大**
   - 证据：ROAS 2.50，三条里最高。
   - 但也不能说它赚钱，要先用成本核对是否高于保本 ROAS，同时确认库存和发货跟得上，再决定要不要加预算。

**还缺什么（补齐后结论可能改变）**
1. 这份表的日期范围，以及三条计划最近有没有新建或改过设置；
2. 单件成本：采购、物流、平台佣金、优惠（有退款率更好）；
3. 每条计划的展示、点击、订单数（用来判断 C3 卡在哪一步）。

先补第 1、2 项就够了，我可以帮你算出保本 ROAS，并给出明确的保留、收缩或暂停清单。
