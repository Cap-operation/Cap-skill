# B05 — 直接上架 3 个商品到 Shopify + 建独立站首页上线（无 DSers / Shopify / Sites 工具）

## 助手回复

先说结论：这次会话里没有 DSers、Shopify 或 Sites 工具，所以"直接上架"和"首页上线"这两件事我都没法执行，状态都记为**未执行**。我也不会给你编造商品链接、预览地址或上线结果。

我现在能做、做完你可以直接拿去用的，有两样东西：

**1. 三个商品的上架资料包（上架大师）**

每个商品一份，包括：标题、详情、变体、售价、划线价，以及按统一利润口径做的核价。另外附一份推送前审阅单，列出目标店铺、可见性，以及推送可能改动的账户物流设置。

等你装好 DSers 并连上 Shopify 店铺后，按这份审阅单批准，就能逐个推送，然后逐个核对后台和前台。

**2. 首页方案 + 本地候选（建站大师）**

- 首页结构：主视觉、主推的 3 个商品、卖点、配送与退换说明，页脚放政策页入口。
- 首页只设一个主行动，比如"去购买"。
- 我会给出可审阅的本地 HTML 或 Shopify 主题（Liquid）候选文件，尚未上传到任何店铺。
- 上线需要 Shopify 官方工具，并完成店铺认证。上线前，替换线上主题还要你单独、明确地批准。
- 页面能打开不等于能卖货。收款、运费、税务和下单链路要分别核实。

**开始前请补这 3 项：**

1. 这 3 个商品的资料：名称、供应商链接或 SKU、采购价、预计物流费、打算的售价、规格。已有资料直接发给我就行。
2. 你已经有 Shopify 店铺了吗？目标市场和币种是什么，比如美国 / USD？
3. 首页的定位：品牌官网，还是单品或活动承接页？

收到后我先出资料包和核价。另外要提醒：采购、物流、佣金、退款这些成本里，任何一项未知，我都不会说"能赚钱"。
