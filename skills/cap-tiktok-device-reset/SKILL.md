# 设备与初始化

## 工作方式

由课前准备入口发起（课前准备上下文）时，先读取 [课前准备流程控制契约](../cap-tiktok-prep/SKILL.md#流程控制契约全局硬规则)，继承当前步骤、状态和待返回位置。跳过、临时答疑、前置阻塞及结束条件按课前准备入口执行；缺少该依赖时不猜测控制规则、不继续顺序陪跑。模块内按现有 SOP 的独立结果建立固定节点编号，不能用“跳过”一次略过整套流程。

单独使用、没有课前上下文时，不套用课程 P 节点流程、跳过规则和结束祝词，只回答设备选择、爱思助手、刷机与初始化；本模块以外的问题简短说明不在本模块范围，交回[总入口](../cap-skill/SKILL.md)。单独使用时按[共用交接约定第 9 节“全程引导”](../cap-skill/references/shared-contracts.md#9-全程引导)带用户：每次留一个出口、卡住先诊断、会用的走快速模式。

先读取 [references/phone-devices.md](references/phone-devices.md) 判断设备。课前准备仅完成设备选择、购买注意事项和爱思助手下载；即使主动询问刷机也不执行，按课前准备入口固定拒答转人工。仅在不带本入口课前准备上下文的独立设备教学中，明确询问刷机才读取 [references/mobile-foundation.md](references/mobile-foundation.md)。爱思助手下载步骤写在 phone-devices.md 的“下载爱思助手”，课前和独立教学共用；Windows 选官网标着“适用本机”的包，Mac 按芯片选 Apple 芯片版或 Intel 芯片版；接受明确文字结果，确需辨认页面才要打码截图。

## 关键流程

默认课前准备只执行 computer-prep 的固定节点 P01、P02，完成后携带状态返回课前准备入口，下一步按电脑模块当前节点表执行 Google 可访问确认，不先追问粉猫、树洞或芯片。以下刷机条目仅供独立设备教学使用，不得从课前准备切换过来，也不得在学员说“停止准备”后绕过限制。

按飞书 1.3 的做法，细节都在 mobile-foundation.md：

- 抹除二选一：电脑上用爱思助手“批量激活/抹除”→“抹除设备”→“开始抹除”→ 勾选同意 →“立即抹除”；没有电脑就在手机“设置”→“通用”→“传输或还原 iPhone”→“抹掉所有内容和设置”。
- 有电脑时用 iMazing 看设备信息：没有“Apple 账户”一行算干净，有就停下转人工。
- 激活：语言和国家或地区按目标市场选，手动设置，连 Wi-Fi，指纹或面容、锁屏密码、Apple ID 都先跳过，不传输 App 与数据，定位服务关闭，其余设置页选以后再设。
- 开机基础设置：飞行模式开、Wi-Fi 开、蓝牙关；关自动更新和后台 App 刷新；时区手动选和所买 IP 同一时区的城市（还没买 IP 先选目标国的一个时区，买好后按 ipleak.net 再改一次；飞书截图的 Chicago 只是例子）；自动锁定选永不；关定位、跟踪、健康、运动与健身和个性化广告。
- 一步一个动作，桌面、设置首页和定位服务页要截图。刷机不是硬件准备阶段的默认步骤；网络配置归入后续账号篇。
