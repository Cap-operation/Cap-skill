# 手机抹除（刷机）、激活与开机基础设置

课程依据：飞书「第 1 章 · 1.3 设备刷机与深度环境伪装指引」（链接见[飞书知识库章节对照](../../cap-skill/references/feishu-map.md)）。本文件只用于不带课前准备上下文的独立设备教学。

每次只带一个动作。关键步骤要学员发截图，截图前遮住序列号、IMEI、Apple ID、邮箱、手机号。锁屏密码、Apple ID 密码、验证码由学员在自己的手机或电脑上输入，不发给 AI。

## 设备选择

- 课程口径：推荐 iPhone 11，美版优先但不是绝对要求，国行也可以（与课前准备入口一致；飞书第 1 章没有单独写机型）。
- 不买监管机、被标记过或有异常记录的设备；购买前向供应商确认设备状态。
- 检查电池、摄像头、麦克风、扬声器、触屏、Wi-Fi 和系统。
- 没有实体卡槽可以接受，手机仍必须能正常连接 Wi-Fi。

## 开始前确认

1. 抹除会清空手机里的全部资料。先备份重要资料，并确认手机是学员本人的或已获授权。
2. 手机开着“查找我的 iPhone”时，抹除后要用这台手机登录过的 Apple ID 和密码才能重新激活（爱思助手抹除确认窗口的提示）。学员不知道这组账号密码就停下，转【船长电商】工作人员。
3. 手机越狱过的，抹除后可能开不了机（同一窗口的提示），先停下转工作人员。
4. 手机里有 SIM 卡的先拔出来。飞书 1.6 要求注册 Apple ID 时“必须拔出物理 SIM 卡”、全程无卡，这台工作机从激活起就不插卡。

有电脑用方案 A，没有电脑用方案 B，二选一。

## 方案 A：电脑上用爱思助手抹除

1. 按 [phone-devices.md 的“下载爱思助手”](phone-devices.md#下载爱思助手) 下载并安装爱思助手；已装好的直接下一步。
2. 用数据线连接手机和电脑。手机弹出“信任此电脑”（英文界面是 Trust）时，学员本人点信任。完成：爱思助手“我的设备”页显示这台手机。
3. 在“我的设备”页下方找到“批量激活/抹除”，点开。
4. 窗口左边点“抹除设备”，确认手机卡片已勾选、显示“可抹除”，点右下角“开始抹除”。
5. 弹出“抹除设备”确认窗口：读完三条提示，勾选“我已阅读并同意以上信息”，点“立即抹除”。
6. 等手机重启回到初始的“你好 / Hello”界面。期间不拔数据线、不关爱思助手、不让电脑休眠。

抹除完成时爱思助手电脑端显示什么，飞书没有截图（需核对），以手机回到初始界面为准。

### 抹除干净的检查（iMazing）

飞书用 iMazing 检查有没有残留，官网 https://imazing.com/ 。有电脑时做：

1. 电脑上装好 iMazing，连上手机，打开“概览”里的“设备信息”。
2. 干净：设备信息里没有“Apple 账户”这一行。
3. 有残留：出现“Apple 账户”，往下还有“Apple 账户个人ID”。这时不要继续激活，发打码截图，转工作人员（飞书没写有残留怎么处理）。

## 方案 B：手机上直接抹除

1. 打开“设置”→“通用”，拉到最下面，点“传输或还原 iPhone”。
2. 点“抹掉所有内容和设置”，再点“继续”。
3. 按屏幕提示操作，等手机重启回到初始界面。

iOS 版本不同，界面会有差别；和描述对不上时要截图，不猜按钮。

## 激活（手机回到“你好 / Hello”以后）

飞书以英语界面、美国市场为例，按钮名照英文界面写。

1. 语言选 English，或目标市场的语言。
2. 国家或地区选目标市场：做美国选 United States，做英国选 United Kingdom。
3. 出现 Quick Start（快速开始）时，点 Set Up Manually（手动设置），不从别的手机传数据。
4. 选一个 Wi-Fi 连上，点 Next，等 “It may take a few minutes to activate your iPhone” 这一页过去。
5. Data & Privacy 页面点 Continue。
6. 指纹或面容设置页选以后再设（飞书截图是 Touch ID：Set Up Touch ID Later，弹窗选 Don't Use）。
7. 创建锁屏密码页选不设密码（飞书截图的弹窗选 Don't Use Passcode）。
8. Apps & Data 页面选 Don't Transfer Apps & Data。
9. Apple ID 页面先不登录：点 “Forgot password or don't have an Apple ID?” → “Set Up Later in Settings” → 弹窗选 Don't Use。Apple ID 之后按 `cap-tiktok-apple-id` 在设置里注册。
10. Terms and Conditions 页面点 Agree。
11. Express Settings 页面点 Customize Settings（自定义设置）。
12. Keep Your iPhone Up to Date 页面点 Continue。
13. iMessage & FaceTime 页面点 Not Now。
14. Location Services 页面点 Disable Location Services，弹窗点 OK。
15. Siri 页面点 Set Up Later in Settings。
16. Screen Time 页面点 Set Up Later in Settings。
17. iPhone Analytics 页面点 Don't Share。
18. 后面再出现的设置页都选跳过或以后再设，直到进入桌面。

完成：进入桌面，学员发一张桌面截图。第 6、7 步的按钮在不同机型和系统上名字不一样，对不上时看截图再指。

## 开机基础设置

1. 打开“设置”首页：打开飞行模式，打开 Wi-Fi 并连上，关闭蓝牙。截图这一页。
2. “通用”→“软件更新”→“自动更新”：把自动下载和安装关掉。
3. “通用”→“后台 App 刷新”：设为关闭。
4. “通用”→“日期与时间”：关掉“自动设置”，时区选和你所买 IP 同一时区的城市。还没买 IP 时先选目标国的一个时区，买好 IP 后按 ipleak.net 显示的时区再改一次（IP 检测模块会核对）。飞书截图里选的 Chicago 只是例子，不是固定选它。
5. “显示与亮度”→“自动锁定”：选“永不”。
6. “隐私与安全性”→“定位服务”：关闭；同一页的 Location Alerts（定位提醒）里，“Show Map in Location Alerts”也关闭。截图定位服务页。
7. “隐私与安全性”→“跟踪”（Tracking）：点进去关闭。
8. “隐私与安全性”→“健康”和“运动与健身”：里面所有开关都关。
9. “隐私与安全性”→“Apple 广告”（Apple Advertising）：关闭“个性化广告”。

做完以上九项，这台手机的初始化就完成了。网络配置（小火箭、IP）属于后续账号篇，不在这里做。

## 停下和求助

- 遇到激活锁、监管提示、抹除失败或 iMazing 显示有残留：停止操作，整理提示原文和打码截图，转【船长电商】工作人员。
- 学员同一步第二次卡住：指到飞书「第 1 章 · 1.3 设备刷机与深度环境伪装指引」的「一、深度刷机与恢复出厂设置」，那里有图和视频；第三次还不行转工作人员（问怎么找时，请他在社交媒体搜索“船长电商”）。
