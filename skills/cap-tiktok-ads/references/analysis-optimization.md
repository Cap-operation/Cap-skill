# 效果分析与优化

核对日期：2026-10-31。用户要求“分析”“给建议”时默认只读；实际调整另按 [执行授权与恢复](authorization-recovery.md) 判断。

## 先固定可比较的口径

读取当前报表工具说明，明确以下信息后再计算：

- advertiser、广告产品、campaign / ad group / ad / 商品 / 场次等对象与层级；
- 账户时区、报表开始与结束、是否包含当前未结束的自然日；
- 币种、金额单位、含税 / 不含税等已知限制；
- 维度、过滤器、指标、归因窗口、按转化发生或归因日期等时间口径；
- 数据更新时间、接口延迟、退款 / 取消是否已计入以及隐私或阈值限制。

同名指标不保证同义。普通广告、GMV Max、Seller Center 和订单报表的时间及归因口径无法对齐时并列展示差异，不强行对账成一个精确数。

## 完整读取与计算

1. 按工具返回的分页、游标或分段限制读取所需范围，持续到明确结束；独立请求可并行，但同一分页链必须依赖上一页结果。
2. 避免同一对象、日期与维度重复，核对汇总行与明细的关系；不能把 campaign 和其下 ad group 的花费相加。
3. 响应截断、翻页失败、配额不足或缺指标时，标明覆盖范围和未获取部分；不要把第一页当完整账户结论。
4. 缺失、未成熟、隐私屏蔽和真实零值分开。分母为零或缺少必要字段时写“暂不可计算”，不填虚构的零或无穷大。
5. 同币种同口径聚合基础分子分母后再算比率，不简单平均各广告的 CTR、CPA、ROAS 或 ROI。不同币种先分别列示；确有必要换汇时写明汇率、日期与来源。

常用比率按当前工具定义核对：CTR 通常为点击 / 展示，CPC 为花费 / 点击，CPA 为花费 / 对应转化；CVR 必须写出具体转化事件和分母。不能把“订单”“支付”“购买事件”和“成交件数”混作一个指标。

## ROAS、GMV Max ROI 与利润

| 口径 | 应如何解释 |
|---|---|
| 普通广告 ROAS | 对应归因收入 / 广告花费，注明事件、窗口和报表定义；不能自动视为广告净增量 |
| Product GMV Max ROI / 总 GMV | 按当前产品定义核对自然、付费、达人及商品覆盖范围；与普通付费归因 ROAS 分列 |
| LIVE GMV Max | 核对场次、直播 / 非直播收入和归因范围；不能默认与 Product 指标完全等价 |
| 店铺净收入与贡献利润 | 结合实收、采购、包材、物流、平台费、达人佣金、优惠、退款、税费和广告等成本 |

Product GMV Max 的官方效果评估包含自然等流量贡献，不能把其整体 ROI 直接当成纯付费效果。当前 LIVE 或其他产品的非直播收入范围必须再核对官方说明，不横向套用。

沿用 [贡献利润口径](../../cap-skill/references/profit.md)；成本、退款或取消未齐时提供可计算部分和缺口，不宣称盈利。平台广告报表与净收入均不直接证明因果增量；要判断增量时建议使用当前账户支持的合规实验方法。

## 延迟与观察窗口

报告更新时间不等于转化数据成熟。当前官方说明中，GMV Max 报表可能最多延迟约 24 小时；以具体接口、日期和最新说明为准。频繁轮询不能消除延迟，不能每次出现低 ROI 就立即改预算。

普通广告也考虑点击到成交的延迟、窗口回填、学习状态和样本量。刚创建、刚改预算 / 目标、仍在学习或转化尚未成熟时，标注观察限制；使用用户规则和当前官方建议确定观察及冷却期，不发明统一的最小花费、订单数或改动百分比。

GMV Max 当前官方建议避免频繁调整 ROI，并按日等有意义窗口观察；这不是任何场景都必须等待一天的绝对规则。预算失控、违规、库存或履约风险按用户已授权停止规则及时处理，不能因“等数据”忽略风险。

## 从证据到建议

每次围绕主要瓶颈提出必要建议，不机械凑数量。独立教学中的拓展遵守课前准备入口的相关限制；用户要求深入分析时可以在同一课题内展开。

| 现象 | 需要的证据 | 候选动作 |
|---|---|---|
| 不消耗 | 审核 / 产品资格、排期、预算、目标、受众和账户限制 | 先修资格与配置，再评估目标或预算 |
| 有曝光无点击 | 素材 / 商品匹配、开头、展示质量与分布 | 检验一个素材或卖点假设 |
| 有点击无成交 | 落地页 / 商品卡、价格、运费、库存、事件追踪 | 修转化路径，不立即加预算 |
| ROI / ROAS 下滑 | 数据成熟度、归因、竞价、素材疲劳、退款和组合变化 | 根据证据选择一个主要变量 |
| 成交增长但利润下降 | 优惠、佣金、物流、退款和广告叠加 | 收缩或修成本，视授权处理 |

建议条目包含：目标对象、关键数据与时间、可能原因、拟改值、额度影响、观察窗口、预期指标相对基线的方向和停止条件。区分“数据表明”和“待验证假设”。

测试创意、受众或目标时尽量保持其他主要变量稳定，按预先说明的对照和成熟窗口评估；有限数据不包装成统计显著或确定因果。结合库存与履约承接能力，不能仅因报表 ROI 高就扩大预算。

## 执行与交付

有批准且在范围内时，再把建议转为明确的变更计划并写入。执行前重新读取最新对象和预算；分析到执行之间已经有人改动的，先处理冲突，不直接覆盖。

交付包含：口径与覆盖范围、关键发现、建议或实际操作、观察和停止条件。已执行的附对象 ID、前后值和回读结果；只分析的写“本次只读，以下为建议”。没有建立宿主调度时不写“我会持续盯盘”。
