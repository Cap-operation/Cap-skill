# 普通广告与 Smart+ 生命周期

核对日期：2026-10-31。适用于普通 TikTok Ads 和当前账户支持的 Smart+。Shop Product / LIVE GMV Max 另读 [GMV Max](gmv-max.md)；任何写入同时读 [执行授权与恢复](authorization-recovery.md)。

## 输入与草案

按目标和当前 schema 补齐必要输入，不把这份清单当固定 API 参数表：

| 输入 | 判断重点 |
|---|---|
| 广告账户与目标 | advertiser ID、市场、币种、时区、业务目标、普通广告或 Smart+ |
| 转化目的地 | 网站、应用或 Shop 等当前工具支持的目的地；对应像素 / 事件 / 应用 / 店铺权限 |
| 结构与周期 | campaign、ad group、ad 的关系；开始与结束时间、已有对象复用或新建 |
| 预算与竞价 | 预算归属层级、日 / 总额语义、目标与出价、最大新增额度、允许变化范围 |
| 受众与版位 | 当前产品允许设置的地域、年龄、受众和版位；受限制商品遵守适用政策 |
| 素材与身份 | 视频 / 图片 / 文案、落地页、展示 identity；Spark 或达人素材的广告授权、有效期 |
| 测量 | 当前优化事件、归因窗口、报告日期和口径；不能用失效事件或未授权数据来源 |

读取当前工具可用的目标、枚举和约束；不能凭经验硬编码预算下限、广告层级、状态或投放市场。Smart+ 的自动化字段与普通广告不一定兼容，不复制旧版 Smart Performance Campaign 或其他产品参数。

优先复用用户已提供的合法素材和已授权身份。新建 / 上传素材、生成落地页或取得 Spark 授权若不在本次任务范围，先在草案中列为依赖。不得自动联系达人、购买素材或上传客户名单。

## 新建顺序

1. 读取现有结构，确认是否已有本次计划对应对象，避免重复创建；名称仅用于辅助，不能单独证明身份。
2. 给出可审阅草案：目标账户、广告产品、各层对象关系、素材、预算、时段、目标状态及最大可能新增消耗。说明平台限制、缺失字段和不能保证的事项。
3. 检查已有用户批准是否覆盖本次创建和开投；创建 API 对象本身也是写入，不能以“只是草稿”省略授权判断。
4. 按依赖创建：仅在需要时新建上层对象，再使用真实返回 ID 创建下层对象。使用当前 schema 支持的暂停 / 非投放状态；不能保证非投放时，未获开投授权则止于文本草案。
5. 每次保存返回 ID，检查对象归属与创建状态。上层失败时停止下游，不使用猜测 ID。
6. 回读预算、状态、素材、时间与追踪配置。创建成功、审核通过和实际投放分别报告。
7. 用户批准启投且验证通过时，调用已发现的当前状态更新工具；不把连接授权当作启投授权。

若当前工具不支持暂停创建，明确说明创建可能立即消耗，并要求用户对相应账户、预算、开始时间和对象作出开投授权；没有授权就不创建。GMV Max 不套用普通广告的暂停假设。

## 更新与启停

每次写入前读取对象最新值，确认对象属于计划、字段可编辑、无人工冲突。按差异更新，不把完整旧配置原样覆盖回去。

每项变更记录：对象 ID、修改前后值、业务原因、额度与时段影响、预期验证结果。提高预算、延长投放、扩展地域、降低回报目标或改变竞价可能增加花费，先判断是否处于批准范围。

暂停、恢复、复制、删除、变更绑定和改变状态都属于写入。恢复尤其可能重新产生消耗，不能将“排错”“刷新状态”当作恢复授权；删除不作为默认纠错动作。

Smart+ 对同一 ad 的写入遵守官方 MCP guide 当前限制：每 5 秒最多 1 次。合并同一对象可合并的字段，避免并发更新和自动化互相覆盖；平台返回更严格限制时从严执行。冷却与重试通过宿主能力实现，不建无期限循环。

## 素材与审核

素材可读取不代表有广告使用权。核实 identity、素材授权类型、有效期、适用账户和落地页一致性；授权过期或无法确认时不上传 / 不启投。

审核拒绝时先读取官方原因，核对商品和广告政策，提出合规修正。不得用更换账户、隐藏违规信息、伪造证明、规避识别或未经授权复用他人素材来通过审核。

## 失败和交付

发生超时、部分创建或结果未知时，执行授权参考的“先核对、再补缺”流程。广告系统的多步创建不应被承诺为原子事务；只报告有证据的成功项。

交付表可按实际结果缩减：

| 对象与 ID | 动作 | 修改前→修改后 | 账户时间 | 平台返回 / 回读状态 | 后续动作 |
|---|---|---|---|---|---|
| 实际对象 | 实际动作 | 实际值 | 含时区 | 已验证、失败或待验证 | 仅保留必要事项 |

只输出草案时不填写虚构 ID；说明尚未执行。已写入但未通过审核时不能写“已投放”，已启用但无消耗时不能写“已经拿量”。

来源见 [官方来源](official-sources.md) 的 MCP guide、工具目录和广告政策；字段与工具能力以实时 schema 为准。
