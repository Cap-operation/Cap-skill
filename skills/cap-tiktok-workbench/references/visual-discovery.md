# 视觉挖掘

老板是视觉动物：先被画面打动，才愿意往下聊功能。所以第一步不问生意，先给看；视觉要从多个维度挖透，功能放在后面。

## 四条铁律

1. **先给看，再问。** 每个视觉问题之前，老板都要已经看到对应的效果（风格画廊、当场切换、截图）。不让老板凭想象回答“你喜欢什么风格”。
2. **选项和屏幕上的字一模一样。** 问题里的每个选项，老板都能在屏幕上找到同名的分组、画面或按钮（画廊的分组标题、画面名、控制台按钮）。不出现屏幕上没有的词：英文名、零件 id、术语，也不用屏幕上没有的形容词去代指画面。
3. **一次一个维度，点选为主。** 每题 2–4 个选项加“其他”；能对比就对比（“左边这种还是右边这种？”）。老板说“你定”就用推荐项，并说“随时能换”。
4. **把他的生意变成画面。** 卖到哪些国家 → 地球上的光弧；有几个人的活 → 几个小人；公司名 → 开场动画里逐字打出来。让老板看到“这是我的公司”，而不是一个模板。

## 第一分钟：直接给看

老板一开口（哪怕只说了“我想搭个工作台”），先猜一个最接近的行业模板生成画廊，不先问问题：

```bash
python3 scripts/new_workbench.py --list-templates
python3 scripts/new_workbench.py --template tiktok-shop --out <临时文件夹> --gallery
```

| 老板说的 | 用模板 |
|---|---|
| TikTok、短视频带货、东南亚 | `tiktok-shop` |
| 独立站、Shopify、品牌站、欧美 | `shopify` |
| 亚马逊、Listing、FBA | `amazon` |
| 工厂、外贸、询盘、B2B、供应链 | `factory` |
| 没说 | `tiktok-shop` |

打开 `gallery.html`（怎么打开见 [SKILL.md 宿主与工具](../SKILL.md#宿主与工具)：内置浏览器先起本机服务再开 http 地址；没有浏览器就告诉他双击），按[开场那段话](../SKILL.md#开场先给看再讲路线)讲六步路线（画廊顶上有同样的路线条），然后马上进入名字上墙。

画廊顶部的“视觉控制台”可以当场切：配色、背景氛围、动感、完成庆祝、开场、品牌色；底部能派活，看每个画面怎么反应。老板点完后，顶部会生成一行“我的视觉卡”，他可以直接把这行发回来。

## 名字上墙

第 1 步一开头就做，排在下面视觉维度第 1 题之前。老板看到自己公司的名字挂在画面上，才会觉得“这是我的公司”，后面挑视觉也更投入。

1. 问：“工作台顶上写你公司的名字，叫什么？”（品牌名、店铺名、公司名都行）选项：直接说名字 / 先用“我的 OPC 公司”。
2. 他一说，马上用他的名字刷新画廊（Logo 上的字默认取名字第一个字，他想换就加 `--mark "<一个字>"`）：

```bash
python3 scripts/new_workbench.py --template <行业> --name "<老板说的名字>" --out <画廊文件夹> --gallery --update
```

3. 刷新后指给他看：画廊标题、每个工作台左上角，再点画廊顶上“开场”那一排任意一个按钮，让他看开场动画把名字逐字打出来。只说一句（如“顶上已经是‘星河宠物’了”），然后问第 1 题（第一眼气质）。
4. 名字放在视觉卡最前面。以后任何一步想改名字都行，改完同样刷新给他看。

- 名字只用在这个工作台的画面和文件夹里，不写进 Skill，也不当 GitHub 搜索词。
- 名字太长（十几个字以上）顶上会挤：建议一个短名，老板同意再用。

## 看图挑选页（第 3–7 题的默认做法）

老板在画廊里点了“就用这个”，视觉卡旁边会出现“下一步：看图挑配色和特效 →”，打开 `pick.html`。这一页按配色 → 背景 → 动感 → 庆祝 → 开场一步一步走。每一步并排放 3–6 个**他自己的工作台**（主场景、岗位都是他的），实时在跑，只有当前这一项不同；他点“选这个”就自动进下一步，全程不用读文字描述。选完后页面显示最终效果和一行视觉卡。

- 老板说“选好了”：能读页面的宿主（如 Claude Code 的内置浏览器）直接读 `window.WB_PICK`（`theme` 和 `line`），读回视觉卡请他确认；读不到就请他点“复制这一行”发过来。
- 文字题只是后备：只能聊天、打不开页面时，才用下面的题目逐个问。不能只给文字描述让老板凭想象选。
- 视觉问题不要用会挡住画面的弹窗提问；老板要一边看画面一边选。

## 十个视觉维度（按顺序，一次一个，已知的跳过）

第 1 步问第 1–7 题和第 10 题，第 3–7 题优先在看图挑选页里完成，下表“怎么问”是打不开页面时的后备说法；第 8 题在第 3 步（应用场景）问，第 9 题在第 4 步（优化）逐个点开岗位时问。

| # | 维度 | 怎么问（先让他看） | 选项（例） | 写进配置 |
|---|---|---|---|---|
| 1 | 第一眼气质 | “画廊分成了四组，哪一组最像你想要的公司？” | 温暖有人味 / 潮酷夜店 / 科技冷酷 / 高级沉稳（就是画廊里的四个分组标题） | 缩小主场景和配色的候选，见下表 |
| 2 | 主场景 | “这一组里的两个画面，首页最大那块用哪个？” | 这一组的两个画面名 + 其他（可以选别的组） | `theme.main_scene` |
| 3 | 配色 | “点上面配色那一排看看，哪个顺眼？有自己的品牌色吗？” | 推荐 2–3 套（用按钮上的名字）/ 用我的品牌色 | `theme.palette`、`theme.accent` |
| 4 | 背景氛围 | “背景想要什么氛围？可以叠两个” | 干净 / 网格 / 星空 / 数字雨 / 极光流动 / 光斑 / 扫描线 里推荐 2–3 个 | `theme.fx` |
| 5 | 动感强度 | “整体要安静一点还是炸一点？” | 安静 / 正常 / 炸裂 | `theme.motion` |
| 6 | 完成庆祝 | “小人干完你派的活，要什么特效？”（点按钮就放一次） | 烟花 / 彩带 / 彗星 / 不要 | `theme.celebrate` |
| 7 | 开场 | “每次打开工作台，要不要开场？”（点按钮就播一次） | 开机自检（岗位逐个上线）/ Logo 亮相 / 不要 | `theme.opening` |
| 8 | 用在哪里 | “这个画面主要在哪儿看？” | 电脑上自己用 / 投到大屏或电视 / 直播或录视频当背景 / 手机上看 | 大屏、直播：交付时教他点“大屏”，背景选得更亮、动感不低于正常；手机：主场景避开 `node-matrix`、`pipeline` |
| 9 | 岗位画面 | “点开每个岗位看到的画面，有想换的吗？”（在正式工作台里逐个点给他看） | 都可以 / 换某个岗位 | 各岗位 `module` |
| 10 | 灵感参考 | “有没有你特别喜欢的画面？电影、游戏、别人的大屏、截图都行，发给我” | 发一张 / 没有 | 只提取氛围（颜色、亮暗、动感、元素），映射回 1–7 维；不照抄具体作品的角色、标志或画面 |

第 8 题放到第 3 步，是因为老板看过效果、说清了自己的公司以后，才知道主要在哪儿用。

### 气质 → 候选

画廊按这张表分组，每个画面只属于一组（顺序同画廊）。改分组时两边一起改；后来装进零件库的画面先放在画廊的“更多画面”组。

| 气质（画廊分组） | 这一组的画面 | 配色候选 | 背景 | 动感 | 庆祝 |
|---|---|---|---|---|---|
| 温暖有人味 | 像素办公室 `pixel-office`、全球市场 `globe` | 极光绿紫 `aurora`、翡翠绿 `jade` | 光斑 | 正常 | 彩带 |
| 潮酷夜店 | 霓虹赛博 `neon-grid`、神经星河 `neural-galaxy` | 霓虹粉紫 `neon` | 扫描线 + 星空 | 炸裂 | 烟花 |
| 科技冷酷 | 数据漩涡 `data-vortex`、信号总线 `node-matrix` | 赛博青 `cyber`、冰蓝 `ice` | 网格 + 数字雨 | 正常 | 彗星 |
| 高级沉稳 | 能量流体 `energy-flow`、流水线 `pipeline` | 琥珀金 `amber`、冰蓝 `ice` | 极光流动 | 安静 | 彩带 |

第 2 题只给这一组的两个画面；老板说过“要炫酷”“不要死板”时，高级沉稳组先推荐能量流体，流水线放到岗位画面里。

## 怎么追问，才能挖到老板真正想要的

- **先夸张再收：** 第一次给看时把动感调到“炸裂”、背景叠两层，让他先被震一下；他说“有点乱”再收，比从素往上加容易得多。
- **问“哪里”而不是“喜不喜欢”：** 老板说“感觉不对”时，给选项定位：太暗 / 太花 / 太素 / 字太小 / 动得太快 / 颜色不搭。
- **两两对比：** 拿不定主意时，只留两个，当场切换给他看，问“左还是右”。
- **用他的东西：** 有 Logo 就取主色当品牌色；卖到哪些国家就让地球亮起那些国家；常说的那句话就做成派活栏的快捷指令。
- **每轮读回视觉卡：** 每定一个维度，就在回复里更新一行视觉卡，让他看到自己的选择在累积。

## 视觉卡（视觉挖掘的产出）

```text
我的视觉卡：名字 星河宠物｜主场景 像素办公室｜配色 赛博青（品牌色 #FF7A00）｜背景 星空 + 光斑｜动感 炸裂｜庆祝 烟花｜开场 开机自检
```

老板确认视觉卡后进入第 2 步（功能按键），先用视觉卡[试装](build-and-debug.md#试装)工作台给他看。视觉卡的值写进 `company.json` 的 `theme` 和 `company.name`、`mark`（字段见[数据插座](state-contract.md)）。

## 优化阶段的视觉精修

第 4 步（优化）先做视觉精修，按下面的顺序一项一项过（每次只改一项，改完立刻给他看）：

1. 远看：退后两米或投到大屏，主场景是否一眼抓人、公司名是否看得清；
2. 亮度与对比：太暗就换更亮的配色或去掉扫描线，太花就减一层背景；
3. 密度：岗位太多显得挤，就换 `neural-galaxy` 或减少岗位；
4. 节奏：动感、庆祝、开场是否让他“想多看两眼”而不是“晃眼”；
5. 每个岗位抽屉：逐个点开，问“这个岗位的画面满意吗？”。

视觉精修完再过[调试清单](build-and-debug.md#调试清单)。老板中途主动问接口，简短回答后回到当前这一项。
