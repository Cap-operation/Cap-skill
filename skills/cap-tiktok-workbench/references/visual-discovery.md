# 视觉挖掘

老板是视觉动物：先被画面打动，才愿意往下聊。第 1 步不问生意，先给看，只问三件事：名字、首页画面、配色。其余视觉（背景、动感、庆祝、开场）按画面所在的组自动配好，第 3 步他想换再换。

## 三条铁律

1. **先给看，再问。** 每个视觉问题之前，老板都要已经看到对应的效果（风格画廊、看图挑选页、当场切换）。不让老板凭想象回答“你喜欢什么风格”。
2. **选项和屏幕上的字一模一样。** 问题里的每个选项，老板都能在屏幕上找到同名的分组、画面或按钮（画廊的分组标题、画面名、控制台按钮）。不出现屏幕上没有的词：英文名、零件 id、术语，也不用屏幕上没有的形容词去代指画面。
3. **把他的生意变成画面。** 卖到哪些国家 → 地球上的光弧；有几个岗位 → 几个小人；公司名 → 开场动画里逐字打出来。让老板看到“这是我的公司”，而不是一个模板。

## 第一分钟：直接给看

老板一开口（哪怕只说了“我想搭个工作台”），先猜一个最接近的行业模板生成画廊，不先问问题：

```bash
python3 scripts/new_workbench.py --list-templates
python3 scripts/new_workbench.py --template tiktok-shop --out <临时文件夹> --gallery
```

| 老板说的 | 用模板 |
|---|---|
| TikTok、短视频带货、东南亚 | `tiktok-shop` |
| 独立站、Shopify、品牌站、欧美 | `shopify` |
| 亚马逊、Listing、FBA | `amazon` |
| 工厂、外贸、询盘、B2B、供应链 | `factory` |
| 没说 | `tiktok-shop` |

打开 `gallery.html`（怎么打开见 [SKILL.md 宿主与工具](../SKILL.md#宿主与工具)：内置浏览器先起本机服务再开 http 地址；没有浏览器就告诉他双击），用[开场那句话](../SKILL.md#开场先给看一句话讲路线)讲路线，然后马上问名字。

## 名字上墙

1. 问：“工作台顶上写你公司的名字，叫什么？”（品牌名、店铺名、公司名都行）选项：直接说名字 / 先用“我的 OPC 公司”。
2. 他一说，马上用他的名字刷新画廊（Logo 上的字默认取名字第一个字，他想换就加 `--mark "<一个字>"`）：

```bash
python3 scripts/new_workbench.py --template <行业> --name "<老板说的名字>" --out <画廊文件夹> --gallery --update
```

3. 刷新后只说一句（如“顶上已经是‘星河宠物’了”），紧接着问首页画面。
4. 名字放在视觉卡最前面，以后任何一步想改都行。

- 名字只用在这个工作台的画面和文件夹里，不写进 Skill，也不当 GitHub 搜索词。
- 名字太长（十几个字以上）顶上会挤：建议一个短名，老板同意再用。

## 挑首页画面

问：“首页最大那块用哪个画面？看中了点它右上角的‘就用这个’。”画廊已经按第一眼的感觉分好组（温暖有人味 / 潮酷夜店 / 科技冷酷 / 高级沉稳），不再单独问气质。

- 选项给 2–3 个画面中文名加“其他”：按[风格配方](scene-recipes.md)的行业推荐排前面；老板说过“要炫酷”“不要死板”时，先推荐潮酷夜店或科技冷酷组的画面。
- 他点了“就用这个”，画廊会按这个画面所在的组自动配好背景、动感、庆祝（见下表），并亮出“下一步：挑配色 →”。他在顶上控制台自己点过的那几项，保持他点的。

## 挑配色（看图挑选页）

打开 `pick.html`：一排并排放 6 个**他自己的工作台**，实时在跑，只有颜色不同，这一组推荐的配色排在前面并标“推荐”。他点“选这个”就完成，页面显示最终效果和一行视觉卡。有自己的品牌色就在画廊顶上“品牌色”里取。

- 老板说“选好了”：能读页面的宿主（如 Claude Code 的内置浏览器）直接读 `window.WB_PICK`（`theme` 和 `line`）；读不到就请他点“复制这一行”发过来。读回视觉卡这一行，直接进第 2 步，不单独等他确认；他说要改就改。
- 只能聊天、打不开页面时，才用文字问配色，给 2–3 个推荐名字。不能只给文字描述让老板凭想象选。
- 视觉问题不要用会挡住画面的弹窗提问；老板要一边看画面一边选。

### 气质 → 自动配置

画廊按这张表分组，每个画面只属于一组（顺序同画廊）。老板点“就用这个”后，背景、动感、庆祝按这一组自动配好；配色候选排在看图挑选页前面。开场默认“开机自检”。改分组时画廊、看图挑选页和这张表一起改；后来装进零件库的画面先放在画廊的“更多画面”组，不自动配置。

| 气质（画廊分组） | 这一组的画面 | 配色候选 | 背景 | 动感 | 庆祝 |
|---|---|---|---|---|---|
| 温暖有人味 | 像素办公室 `pixel-office`、全球市场 `globe` | 极光绿紫 `aurora`、翡翠绿 `jade` | 光斑 | 正常 | 彩带 |
| 潮酷夜店 | 霓虹赛博 `neon-grid`、神经星河 `neural-galaxy` | 霓虹粉紫 `neon` | 扫描线 + 星空 | 炸裂 | 烟花 |
| 科技冷酷 | 数据漩涡 `data-vortex`、信号总线 `node-matrix` | 赛博青 `cyber`、冰蓝 `ice` | 网格 + 数字雨 | 正常 | 彗星 |
| 高级沉稳 | 能量流体 `energy-flow`、流水线 `pipeline` | 琥珀金 `amber`、冰蓝 `ice` | 极光流动 | 安静 | 彩带 |

## 视觉卡（第 1 步的产出）

```text
我的视觉卡：名字 星河宠物｜主场景 像素办公室｜配色 赛博青（品牌色 #FF7A00）｜背景 光斑｜动感 正常｜庆祝 彩带｜开场 开机自检
```

视觉卡的值写进 `company.json` 的 `theme` 和 `company.name`、`mark`（字段见[数据插座](state-contract.md)），第 2 步生成正式工作台时用。

## 第 3 步的视觉调整

第 3 步（调到满意）老板说哪里不对，先用选项定位，再当场改给他看，一次改一处：

- **定位而不是问“喜不喜欢”：** 老板说“感觉不对”时，给选项：太暗 / 太花 / 太素 / 字太小 / 动得太快 / 颜色不搭。
- **两两对比：** 拿不定主意时只留两个，当场切换给他看，问“左还是右”。背景、动感、庆祝、开场要并排比时，打开 `pick.html?steps=fx,motion,celebrate,opening`（只列要比的那几项），和挑配色一样点选。
- **主要在哪儿看：** 第 3 步问一次：电脑上自己用 / 投到大屏或电视 / 直播或录视频当背景 / 手机上看。大屏、直播：背景选得更亮、动感不低于正常，交付时教他点「大屏」；手机：主场景避开信号总线、流水线（用画面中文名给替换建议，老板同意再换）。
- **岗位画面：** 逐个点开岗位给他看，问“这个岗位的画面满意吗？”。
- **灵感参考：** 老板主动发了截图、电影、游戏或别人的大屏才用：只提取氛围（颜色、亮暗、动感、元素），映射回配色、背景、动感；不照抄具体作品的角色、标志或画面。不主动索要。
- **用他的东西：** 有 Logo 就取主色当品牌色；卖到哪些国家就让地球亮起那些国家；常说的那句话就做成派活栏的快捷指令。

每改一处，更新说明书里的视觉卡。
