# 工作台风格

给工作台加东西、改样子、做新画面时用。谁动手都一样：Claude、顾问，或者老板自己用 AI 编程工具（vibe coding）。挑现成画面和配色见[风格配方](scene-recipes.md)；零件和数据格式见[数据插座](state-contract.md)；这份只管“新做的东西长什么样、放在哪里”。生成工作台时，本文件会复制一份到工作台文件夹的 `给AI看的说明/`。

## 一句话风格

深色的 AI 公司指挥中心：一眼看到谁在干活、干到哪了、交了什么。它不是报表系统，也不是游戏。三个词：**有人味、在运转、分得清真假**。

## 六条铁律

1. **颜色只用变量。** 只用外壳定义的 CSS 变量：底色 `--bg` `--bg2`，面板 `--panel` `--panel-solid`，线 `--line` `--line-strong`，字 `--text` `--muted` `--dim`，主色 `--accent` `--accent2`，状态 `--ok` `--warn` `--bad` `--boss`，岗位轮换色 `--c1`–`--c6`；岗位自己的颜色用 `wb.roleColor(id)`。不写死任何色值，换配色（`theme.palette`）或品牌色（`theme.accent`）时新东西要跟着变。老板要某种颜色（比如“土豪金”），色值只写在一个地方：`theme.accent` / `accent2`，或在 `custom/custom.css` 里重新定义上面的变量；其他地方都引用变量。
2. **真假分得清。** 没接通的数字和成果标“模拟”（`.tag.sim` / `.badge.sim`，黄点）；接通的标“已接通”（`.tag.live` / `.badge.live`，绿点）；部分接通显示“部分接通 x/y”。状态词只用：模拟、已接通、部分接通、待验证。读不到真实数据时保留上次的数，不把模拟数字显示成“已接通”，也不填 0。
3. **数据要变成画面。** 新东西要让“活在动”看得见：岗位的四种状态（走向工位、干活、汇报、待命）都要有样子，老板派的活完成时要有汇报。只让一个数字跳动不算画面。没有任务时也要好看：待命动画或一句白话，不留空白框。
4. **先找现成的位置，不加新栏。** 一个数 → 顶栏数字（3–6 个）；一个岗位的细节 → 岗位抽屉；一段流程 → 流水线（`flows`）；一种新画面 → 新零件；一句常用的话 → 快捷指令。确实要加面板，用 `.panel` + `.panel-h` + `.panel-b`，不改“左岗位、中主场景、右任务流和日志、底派活栏”的结构。
5. **老板自己的改动放 `custom/`。** 样式写 `custom/custom.css`，脚本写 `custom/custom.js`，自己做的零件放 `custom/parts/<id>/`（结构见[数据插座 §6](state-contract.md#6-老板自己的改动-custom)）。`core/`、`parts/`、`sources/`、`index.html` 每次更新都会被覆盖，不在里面改。
6. **不联网、不放秘密。** 不加载外部 CDN、字体、图片；要用的库随零件放进文件夹并带许可证。令牌、密码、Cookie 不写进任何页面、样式、零件或 `data/`。

## 字

- 白话，老板的话：写“今日订单”，不写 “Order Count”；写“回客户消息”，不写“工单处理”。标签不超过 6 个字。
- 数字一律用 `.mono`（等宽、对齐）。金额带币种前缀，同一个面板里只用一种币种；比率保留 2 位小数。
- 字号三档：顶栏大数 17–22px，正文 13–14px，次要说明 11–12px。面板标题用小号字加字间距（沿用 `.panel-h`）。
- 不用感叹号，不堆 emoji，不写“智能赋能”“全链路”这类空词。

## 形状与光

- 面板：半透明 `--panel` + 1px `--line` 描边 + 14px 圆角 + 背景模糊；弹层、抽屉用不透明的 `--panel-solid`。
- 按钮沿用 `.tbtn`（工具按钮）、`.chip`（快捷指令）、`.go`（主按钮，accent 到 accent2 的渐变）。一屏只有一个主按钮。
- 发光只给“正在发生的事”：干活中的岗位、刚完成的任务、老板派的活。静止的东西不发光，否则满屏都亮等于没亮。

## 动

- 跟着 `theme.motion` 走：安静、正常、炸裂三档，新动画的速度和幅度也分三档。
- `wb.reducedMotion` 为真（系统开了“减少动态效果”）时停掉连续动画，只保留状态变化。
- 庆祝特效只在老板派的活完成时放，自动任务不放。
- 闪烁每秒不超过 3 次。用 canvas 的零件用 `requestAnimationFrame`，`destroy` 时停掉循环和监听；大屏模式下不能明显掉帧。

## 画面元素

- 每个岗位要有一个看得出“是个人”的形象：小人、星球、卡片都行，但要有名字、有颜色、有状态。老板在画面中心或顶部。
- 像素素材按整数倍缩放，加 `image-rendering: pixelated`；图片缩到显示尺寸的 2 倍以内。
- 灵感参考只取氛围（颜色、亮暗、动感、元素），不照抄具体游戏、电影、品牌的角色、标志或画面。
- 不写死业务数字、品牌名、案例：画面里显示的数都来自状态（任务数、进度、完成数、顶栏数字）。

## 尺寸

- 1024×768 到 1920×1080 都要能看：1280 以下三栏变窄，1024 以下改成上下堆叠；大屏模式只留顶栏、主场景和派活栏。
- 新零件按[零件规范](parts-catalog.md#零件规范)适配 2–14 个岗位、640×360 到 1920×1080 的容器。

## 不要做的

- 白底或浅色主题；首页最大那块用纯表格或纯图表（老板说过“不要死板”时更不行）。
- 一屏塞超过 8 个数字；把模拟数字写进汇报、截图说明或给客户的材料。
- 改 `core/`、`parts/`、`index.html` 里的原文件；把英文字段名、文件路径直接显示在画面上。

## 改完自查

1. 换一套配色、更新一次，新东西的颜色跟着变。
2. 1280×720、1920×1080、1024×768 三档各看一眼：不重叠、不裁切。
3. 模拟、已接通的标注都在，没有把模拟说成真的。
4. 浏览器控制台没有红色报错。
5. 打开“减少动态效果”后不再连续乱动。
6. 用生成器更新一次，自己的改动还在。
