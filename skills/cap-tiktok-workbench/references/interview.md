# 定公司

第 2 步用。视觉已经在第 1 步按[视觉挖掘](visual-discovery.md)定好（视觉卡，带公司名字）。这一步只问两道题，其余按行业模板和岗位自动配好，直接生成正式工作台给老板看。老板不需要懂技术，也不需要写长段描述。

## 提问规矩

- 一次一个问题。每题 2–4 个选项加“其他”；能多选的写明“可多选”。
- 选项用老板的话，不用术语：说“回客户消息”，不说“客服工单”；说“看今天卖了多少”，不说“GMV 看板”。
- 老板答“不知道 / 你定 / 都行”，或只说“继续”“下一步”没回答当前问题：选推荐项并告诉他“先按 X，后面随时能改”，不追问。
- 老板前面已经说过的（比如开口就说“卖美国”“我要客服和选品”），直接用，不再问。
- 顾问代答时同样一次一问，可以把技术细节写在选项说明里。

## 两道题

| # | 问题 | 选项（例） | 写进配置 |
|---|---|---|---|
| 1 | 主要卖到哪些地方？（可多选） | 东南亚 / 欧美 / 中东 / 拉美 | `company.markets`（按地区换成国家代码，老板说了具体国家就用具体的） |
| 2 | 想要哪几个 AI 岗位？选中的会变成办公室里的小人（可多选） | 找品选品 / 做内容视频 / 投广告 / 找达人合作 / 回客户和售后 / 上架和店铺 / 对账算利润 / 发货和供应链 | 岗位（按[岗位模板](#岗位模板)） |

- 第 2 题的选项按行业模板里已有的岗位打勾作为推荐，老板只增删。宿主的提问工具一题放不下 8 个选项时（如 Claude Code 的 AskUserQuestion 每题最多 4 个），仍是一道多选，不拆成两道：第一项“推荐的 N 个”，说明里列出模板里的岗位名；其余最多 3 项“加：<岗位>”，挑模板外最常用的；想去掉某个、或要剩下的岗位，写在问题说明里，让老板在“其他”里写。
- 卖货渠道：第 1 步按老板的话猜了行业模板；老板这一步说的和模板对不上（比如说了“亚马逊”），才补问一句“你主要在哪里卖货？”（TikTok Shop 跨境店 / 独立站 / 亚马逊等平台 / 外贸工厂），换对应模板。
- 一定有“统筹助理”：负责拆解老板的话、汇总日报，放在第一个，不用老板选。岗位总数 2–14 个。
- 老板在“其他”里说了模板外的岗位（如“直播运营”“翻译”），按下表格式现场补一个。

## 自动配好，不问

| 项 | 怎么定 | 写进配置 |
|---|---|---|
| 快捷指令 | 从选中岗位的“每天负责”里各取最常见的一句，4–5 句，带上老板的市场（如“找 5 个美国的爆品”）；第一句也做输入框提示 | `commands.presets`、`commands.placeholder` |
| 顶栏数字 | 按行业从[顶栏数字推荐](#顶栏数字推荐)取，接通前都标“模拟” | `kpis` |
| 口号 | 按岗位数和市场拼一句，如“一个人 · 六个 AI 岗位 · 卖向欧美” | `company.slogan` |
| 岗位画面 | 按[风格配方](scene-recipes.md)，至少 3 种不同零件 | 各岗位 `module` |
| 右上角按钮 | 「大屏」「暂停」两个，不问想不想加；老板以后说要加，能用快捷指令做到的就加成快捷指令 | — |

- 人数（`team_size`）、给谁看（`audience`）不问；老板主动说了就记下。
- 现在用哪些后台或表格，接数据时才问。
- 业务信息让某个视觉更合适或冲突时（卖到很多国家适合给选品岗位配地球），读回公司卡时顺带提出，用画面中文名，老板同意再改。

## 公司卡

生成正式工作台、打开给老板看、当场派一次活之后，读回一张短表，不贴 JSON：

```text
我的公司卡：
工作台：星河宠物（口号：一个人 · 六个 AI 岗位 · 卖向欧美）
卖货渠道：TikTok Shop 跨境店　市场：美国、英国、德国、法国
AI 岗位（6 个小人）：统筹助理｜选品专家｜内容专家｜投流专家｜客服专家｜财务管家
快捷指令：找 5 个美国的爆品／给新品写 3 条带货脚本／看下今天广告花费／整理昨天的差评
顶上数字：今日成交、今日订单、广告 ROAS、AI 完成任务（接通前都是模拟）
```

然后只问一次：“这样对吗？”选项：对，接着调画面 / 要改一处。

卡片和 `company.json` 只放在老板的工作台文件夹里，不写进 Skill。

## 岗位模板

| id | 岗位 | 关键词（派活路由） | 每天负责 | 交付成果 | 建议模块 | 以后可接 |
|---|---|---|---|---|---|---|
| `chief` | 统筹助理 | 安排、计划、汇总、日报、周报、统筹 | 拆解老板的指令；汇总各岗位进度；整理今日日报 | 任务拆解单、今日日报 | `node-matrix` | — |
| `scout` | 选品专家 | 选品、爆品、找品、商品、竞品、榜单 | 扫描平台热销榜；评估候选商品利润；对比竞品价格 | 候选商品清单、竞品对比表 | `globe` | FastMoss / 平台榜单导出 |
| `content` | 内容专家 | 视频、脚本、文案、内容、钩子、口播 | 改写爆款脚本；生成开头钩子；检查字幕与配音 | 带货脚本、钩子合集、成片清单 | `pipeline` | 内容排期表 |
| `ads` | 投流专家 | 广告、投流、预算、roas、gmv max、花费 | 核对昨日广告花费；找出亏钱的计划；给出调整建议 | 投流日报、调整建议 | `energy-flow` | TikTok 广告账户（官方 MCP） |

| `service` | 客服专家 | 客服、买家、消息、售后、差评、退款 | 回复买家消息；整理差评原因；更新常见问题 | 差评分析、客服话术 | `data-vortex` | Chatwoot 客服后台 |

| `site` | 独立站专家 | 独立站、shopify、网站、落地页、转化 | 检查站点转化；更新落地页；跟进支付与配送设置 | 站点周报、改版清单 | `energy-flow` | Shopify 后台 |

### 执行插座默认对接

接数据阶段打开执行插座时，岗位的活默认交给下面的模块去做；写进 `executor.skill`，`connected` 先保持 `false`。“按行业”的岗位按老板的卖货渠道取；老板现场补的岗位也按这张表填。

| 岗位 | `executor.skill` | 能直接做的（只读 / 草案） | 要单独批准的 |
|---|---|---|---|
| 统筹助理 | `cap-skill` | 拆解指令、汇总日报 | — |
| 选品专家 | `cap-tiktok-selection` | 候选清单、评分、测试方案 | 采购、拿样 |
| 内容专家 | `cap-tiktok-breakdown` | 脚本、钩子、多版本 | 发布 |
| 亚马逊模板的 Listing 专家（`id` 是 `content`） | `cap-tiktok-marketing` | 标题、五点、A+ 文案初稿 | 写入亚马逊后台 |
| 投流专家 | `cap-tiktok-ads` | 读报表、出调整建议 | 任何广告创建、改预算 |
| 达人经理 | 按行业：TikTok Shop 跨境店的联盟达人 → `cap-tiktok-shop`；独立站、亚马逊、外贸工厂找 Instagram、YouTube 达人 → `cap-tiktok-social` | 达人名单、建联话术草稿、寄样进度表 | 联系达人、寄样、付款 |
| 客服专家 | `cap-tiktok-service` | 话术、知识库草稿、差评分析 | 发给买家、退款 |
| 店铺运营 | 按行业：TikTok Shop（含外贸工厂在 TikTok Shop 开的店）→ `cap-tiktok-shop`；独立站推送商品 → `cap-tiktok-listing` | 商品资料包、活动报名清单、审阅表 | 推送、上架、报名活动 |
| 财务管家 | `cap-tiktok-roles` | 对账表、月结和现金流草稿（TikTok 结算口径引用店铺篇） | 付款 |
| 供应链管家 | `cap-tiktok-roles` | 补货建议、物流异常表、供应商比价 | 下单、付款 |
| 独立站专家 | `cap-tiktok-site` | 页面方案、本地预览 | 发布上线 |
| 询盘专家、质检专家（外贸工厂） | 暂无对应模块，只模拟：`skill` 留空，`note` 写“暂无对应模块，只模拟” | — | 不打开执行插座 |

利润相关的说法（“计算贡献利润”）只是岗位名称，工作台不计算利润；真实计算按[贡献利润口径](../../cap-skill/references/profit.md)，在接数据阶段由对应模块完成。

## 顶栏数字推荐

| 行业 | 推荐（取前 4 个，最多 6 个） |
|---|---|
| TikTok Shop 跨境店 | 今日成交、今日订单、广告 ROAS、今日内容条数、AI 完成任务 |
| 独立站 | 今日成交、访客数、转化率、广告花费、AI 完成任务 |
| 亚马逊等平台 | 今日成交、今日订单、广告 ACOS、差评数、AI 完成任务 |
| 外贸工厂 / 供应链 | 今日询盘、在途订单、待发货、样品寄出、AI 完成任务 |

“AI 完成任务”是工作台自己数的（`perTask: 1`），一直保留。执行插座接通前，小人干的都是模拟的活，所以它和其他数字一样标“模拟”；公司卡、说明书里写“接通前都是模拟”，不单独说它是真实数字。
