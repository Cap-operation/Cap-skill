# 搭建问题排查

一次只排查一个问题、只让对方做一个动作；做完让他回一句结果或截图。排查完回到原来那一步。同一问题三轮没解决，按下面的[求助单](#求助单)在工作台文件夹写一份，再请对方把它发给【船长电商】工作人员。

## 没有 Python

不管在哪一步（第 1 步生成画廊、生成正式工作台、接数据、启动工作台）都可能遇到：先运行 `python3 --version`（Windows 用 `py -3 --version`）确认。

- Mac：先在终端运行 `xcode-select --install`，装好系统自带的开发者工具就有 `python3`；不行再到 [Python 官网](https://www.python.org/downloads/) 下载 3.10 或更新版本。
- Windows：从官网安装，第一屏勾选 Add Python to PATH；之后命令里的 `python3` 换成 `py -3`。
- 装完关掉终端重新打开，再确认一次版本号，然后回到原来那一步。

## 页面打开是空白或一直在转

| 现象 | 先做 | 原因与处理 |
|---|---|---|
| 双击 `index.html` 一片黑，只有背景 | 请对方按 F12 → Console 截图（顾问可直接看） | 多半是配置格式错了：用 `<本技能文件夹>/scripts/new_workbench.py --company company.json --check` 找出错误，改好 `company.json` 后 `--update` 重新生成 |
| 页面提示“主场景零件没有加载” | 看 `parts/` 里有没有该零件文件夹 | 用 `--update` 重新生成；零件名要和 `theme.main_scene` 一致 |
| 用了 Safari 或很旧的浏览器，画面错位 | 换 Chrome 或 Edge 最新版 | 部分效果需要较新的浏览器 |
| 从微信、网盘里直接点开 | 先把整个文件夹保存到电脑上再打开 | 只打开 `index.html` 一个文件会缺零件和数据 |
| 压缩包里直接双击 | 先完整解压 | 压缩包预览不能加载同目录文件 |

## 动画卡、风扇响

- 关掉其他标签页和录屏软件；大屏模式比三栏模式省资源。
- 电脑开了“减少动态效果”（系统辅助功能）时，零件会自动停掉连续动画，这是正常的。
- 仍然卡：把主场景换成 `pixel-office` 或 `pipeline`（最轻），或在配置里把 `sim.speed` 调低到 0.6。

## 显示问题

| 现象 | 处理 |
|---|---|
| 字太小、挤在一起 | 浏览器缩放调到 100%；岗位超过 10 个时主场景换 `neural-galaxy` |
| 投影仪或电视上被裁掉 | 点“大屏”；仍不行时按调试清单的三档分辨率逐个检查 |
| 中文显示成方框 | Windows 装“微软雅黑”，Mac 系统自带不用处理 |

## 启动脚本（接数据以后才用）

| 现象 | 处理 |
|---|---|
| Mac 双击 `启动工作台.command` 提示无法打开 | 右键 → 打开 → 再点打开；或在终端进入工作台文件夹运行 `python3 start_workbench.py` |
| 双击后黑色窗口一闪就没了 | 多半是电脑上没有 Python 3，按上面[没有 Python](#没有-python)处理 |
| 端口被占用 | 脚本会自动换 8761–8800 之间的空闲端口；都被占说明开了很多个，关掉旧窗口 |
| 页面显示“部分接通”但数字没变 | 看 `data/live.json` 的 `updatedAt` 是不是最新；连接脚本是否还在运行 |

## 接数据时

| 现象 | 处理 |
|---|---|
| 双击 `index.html` 打开，数字还是“模拟” | 浏览器不让双击打开的页面读数据文件；用“启动工作台”打开 |
| 提示“CSV 里没有列…” | 脚本会列出现有的列名，按真实列名改 `sum:<列名>`；后台换了导出格式时常见 |
| 中文乱码或读不了表 | 脚本会自动按中文 Excel 常见的编码再读一次；仍不行，用 Excel“另存为 CSV UTF-8”再试 |
| 数和后台对不上 | 依次核对：时间段（今天还是昨天、时区）、有没有算进取消和退款、币种、导出表是不是只导出了一页 |
| 关掉启动窗口后数字不更新 | “启动工作台”和 `--watch` 都只在窗口开着时有效 |
| 老板把账号密码发过来了 | 提醒他别再发、建议改密码，不复述、不写进任何文件；接数据从导出表开始，不需要密码 |

## GitHub 打不开

1. 先用浏览器打开 `https://github.com`，能打开再试脚本。
2. 浏览器也打不开：多半是网络环境问题。只在对方合法经营、网络合规的前提下，交给总入口的网络环境模块（[小火箭与树洞](../../cap-tiktok-shadowrocket-treehole/SKILL.md)、[IP 检测](../../cap-tiktok-ip-diagnostics/SKILL.md)）处理，处理完回来继续。
3. 浏览器能打开、脚本连不上：电脑用了代理但终端没走代理。顾问可以按自己的代理软件说明给终端设置代理；不要使用来路不明的“GitHub 加速镜像”下载代码。
4. 脚本提示“证书校验失败”：Mac 上打开「应用程序 → Python 3.x」，双击 `Install Certificates.command`，再重试；不要用关闭证书校验的办法绕过。
5. 实在连不上：跳过 GitHub，先用本地零件库完成工作台，告诉老板“这个画面以后网络好了再加”。

## 求助单

同一个问题试了三轮还没解决，在工作台文件夹写一份 `求助单-<日期>.md`，让对方发给【船长电商】工作人员。工作人员看一眼就该知道卡在哪，不用从头问。

```text
# 求助单（<日期>）
想做什么：
做到哪一步：（照工作台说明书的进度写）
卡在哪：（报错原文，或看到的现象）
试过什么：1. … 2. … 3. …（每一轮做了什么、结果是什么）
环境：Mac / Windows；用的 AI 工具；有没有装 Cap-skill；Python 版本
附件：截图文件名
```

求助单里不写密码、令牌、验证码、完整证件号和买家个人信息。

## 安装 Skill 后没生效

- Claude Code 要新开一个会话才会读取新装的 Skill。
- 确认装在 `~/.claude/skills/<名字>/SKILL.md`，不是多套了一层文件夹。
