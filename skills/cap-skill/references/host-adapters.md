# 宿主与工具适配

Cap 使用通用的 Agent Skills 结构（每个模块一个文件夹，内含带 `name` / `description` 的 `SKILL.md`，细节放 `references/`）。它是行为说明，不是程序级权限系统；不同 AI 客户端读取和执行的方式不同。

## 安装要求

- 17 个模块文件夹放在同一个技能目录下，互为同级，相对链接才能解析。
- 只装部分模块时，至少同时带上 `cap-skill`（共用规则）；课前准备另需 `cap-tiktok-prep`、`cap-tiktok-computer-prep`、`cap-tiktok-device-reset`。
- 把 ZIP 发到聊天网页不等于安装。

## 已知宿主差异

| 宿主 | 读取方式 | 说明 |
|---|---|---|
| Codex | 技能目录 + `agents/openai.yaml` 展示元数据 | 3.1 的原用途；`$模块名` 可显式调用 |
| Claude Code | `~/.claude/skills/` 或项目 `.claude/skills/` | 按 `description` 自动选择；忽略 `agents/openai.yaml` |
| 其他支持 SKILL.md 的客户端 | 各自的技能目录 | 以客户端实际能力为准 |

本版本只做了结构校验和离线场景记录，**未在各客户端逐一做安装与行为验收**，不宣称“全部客户端兼容”。

## 工具按当前环境发现

- 每次任务按当前会话实际可见的工具、说明和输入 schema 判断能力，不按工具名猜参数，不把某个客户端的专有调用名写成必需接口。
- 同一能力在不同宿主可能是 MCP、CLI 或插件。只认实际返回结果。
- 静态工具清单只作设计参考；运行时 schema 与之冲突时以运行时为准。

## 外部依赖与降级

| 依赖 | 用于 | 缺失时交付 |
|---|---|---|
| FastMoss CLI/Skill | 选品研究数据 | 用官方数据或用户导出表分析，标明缺实时数据 |
| Shopify 官方工具 | 独立站主题与店铺 | 页面方案和本地候选文件，不写线上链接 |
| 宿主的 Sites 能力 | 承接页预览与发布 | 同上 |
| DSers MCP Product | Shopify/Wix 商品导入与推送 | 商品资料包和审阅表，状态记为未执行 |
| TikTok 官方广告 MCP | 广告读取与写入 | 基于导出报表的分析和可审阅计划 |
| Chatwoot | 客服渠道、知识库、自动化 | 知识库草稿、话术、配置清单 |

这些依赖都不随本仓库分发，需要用户在自己的宿主中单独安装和授权。安装和连接状态按[能力四层](shared-contracts.md#6-能力四层)报告。

## 不承诺的能力

- 宿主没有可靠调度、持久状态和程序级限额时，不承诺后台全天监控或无人值守执行；会话结束即停止。
- 没有读取到的视频、截图或链接，不说看过。
- Markdown 中的“必须”不能保证每个模型都绝不偏离；需要强制时由宿主保存状态并校验。
