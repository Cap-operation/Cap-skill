# 基础模块索引

这些模块保留 3.1 的独立教学内容。由课前准备入口发起时，一律继承[课前准备流程控制契约](../../cap-tiktok-prep/SKILL.md#流程控制契约全局硬规则)，框架外内容固定拒答。单独使用、没有课前上下文时，不套用课程 P 节点流程、跳过规则和结束祝词，只回答本模块主题；模块以外的问题简短说明，交回总入口。

账号与网络的顺序：Apple ID → IP 购买 → 小火箭 → IP 检测。小火箭的单独 IP 参数来自 IP 购买。

| 模块 | 内容 |
|---|---|
| [电脑工具准备](../../cap-tiktok-computer-prep/SKILL.md) | Google 访问、Chrome、Google 账号、NotebookLM；课前准备的唯一节点表 |
| [手机设备初始化](../../cap-tiktok-device-reset/SKILL.md) | 手机准备、爱思助手；刷机资料独立保留，课前不刷机 |
| [美国 Apple ID](../../cap-tiktok-apple-id/SKILL.md) | 注册、验证、App Store、礼品卡 |
| [小火箭与树洞](../../cap-tiktok-shadowrocket-treehole/SKILL.md) | 订阅导入、节点、Socks5、Proxy Pass、连接测试 |
| [TikTok IP 购买](../../cap-tiktok-ip-purchase/SKILL.md) | Miya、IPRoyal、911Proxy 购买规格 |
| [TikTok IP 检测](../../cap-tiktok-ip-diagnostics/SKILL.md) | 归属、风险、DNS、WebRTC、IPv6 检测 |

课程资料缺口（Google 账号飞书 SOP 正文、手机设置原图、客户端安装包、树洞供应商资料）见仓库根 `RELEASE_READINESS.md`（与 `modules.json` 一样不随技能安装，需仓库检出才能读取）。遇到缺口时说明“所需资料未提供”并转【船长电商】工作人员，不按经验补写步骤。
