# Shopify 适配

条件路径：只有当前环境实际具备 Shopify 官方工具并完成店铺认证时才执行写入。否则停在“页面方案 / 本地候选”层级。

## 依赖来源

- Shopify AI Toolkit：<https://github.com/Shopify/Shopify-AI-Toolkit>，MIT 许可，Copyright Shopify Inc.。本包未复制其源码或文档，未锁定提交；若日后抽取实质内容，需固定提交并保留许可通知。
- Shopify CLI 的主题开发与推送能力。具体命令、参数和登录方式以当前官方文档为准，本参考不写死命令行参数。
- 本包没有 Shopify 插件或 CLI 的安装与连接成功证据；安装与认证由用户在其环境完成，不因建站任务自动安装或登录。

## 运行时发现

1. 检查当前宿主是否暴露 Shopify 相关工具，或用户环境是否已有可用的 Shopify CLI。
2. 按实际工具描述与输入 schema 确认能做什么：查询店铺、编辑主题、预览、发布、商品操作等。不臆造工具名、参数或返回字段。
3. 确认目标店铺标识与认证状态；显示名不能代替店铺标识。多店铺时逐一确认，不串店。
4. 工具缺失或认证失败：有界停止，说明缺口，交付本地主题候选；不循环登录、不索取密码或令牌。

## 新店与已有店

- **新店**：开店、选套餐、绑定收款均属用户在 Shopify 官方流程中的账户操作；本模块给出准备清单，不代为注册或付费。
- **已有店**：先读取现有主题、页面和导航，保留用户自定义；修改前记录当前在用主题与版本，便于回退。

## 预览与发布的区别

| 动作 | 性质 | 授权 |
|---|---|---|
| 本地编辑主题文件 | 本地可逆 | 不需额外批准 |
| 本地开发预览（主题开发模式） | 通常不影响线上买家；仍以当前工具说明为准 | 按任务范围 |
| 上传为未发布主题并生成预览链接 | 写入店铺，但不替换线上主题 | 需覆盖该店铺的授权 |
| 发布主题 / 替换线上主题 | 买家立即可见的线上变更 | 需明确批准，写明店铺、主题和替换对象 |
| 改页面、导航、域名、政策、运费、税务、收款 | 店铺设置写入 | 逐项列入授权范围 |

有效授权直接复用；范围外动作（换店铺、加改设置、替换线上主题）补齐差额再执行。

## 商品与其他模块

- 主题中的商品展示依赖店铺内已有商品；创建、导入或批量推送商品交给上架大师。
- 商品 ID 按“共用交接约定”映射到店铺商品与变体，不凭名称匹配。
- 聊天组件和客服入口交给客服大师，本路径只预留位置。

## 验收清单

- [ ] 目标店铺与主题名称、主题 ID/版本已回读确认。
- [ ] 预览链接来自工具返回，并标注是否非公开、是否会过期。
- [ ] 发布时回读在用主题已切换，线上首页、商品页、购物车可打开。
- [ ] 页面检查清单逐项通过或列出缺口。
- [ ] 收款方式已在后台启用（仅核对状态，不读取账户资料）。
- [ ] 配送区域与运费、税务设置已由有权限者配置并核对。
- [ ] 政策页已发布并在页脚可达。
- [ ] 测试下单：仅在平台提供测试模式或用户明确批准时进行，记录订单是否进入后台。

以上任一项未验证，结果停留在“可访问预览”或“已部署网站”，不报“可交易店铺”。正式卖货收款还取决于套餐、商户与地区资格，按当前官方说明核对。
