# 页面检查清单

用于环节 3–8。这是本系统的检查方法，不是平台审核标准；目标市场的法律和平台政策以当前官方说明为准。

## 结构与导航

- 首页、商品/承接页、关于、联系、政策页齐全且可从导航或页脚到达。
- 导航层级简单，移动端菜单可展开、可关闭。
- 每个页面有清晰标题，页面之间不出现空页、占位文字或示例商品。

## 转化路径

- 每页只有一个主行动（购买、加购、跳转店铺、留资），按钮文字与结果一致。
- 从广告/内容入口到下单或留资，步骤可走通且不超过必要的点击。
- 价格、优惠、运费门槛在下单前可见；不制造虚假倒计时或虚假库存紧张。

## 声明必须与商品事实一致

- 规格、材质、尺寸、功效、交期、配送范围、保修与商品事实一致；事实未知的不写。
- 不使用无证据的评价、销量、“第一”“认证”“医学”类表述；他人素材里的经历和数据不移植。
- 商品事实变化后，标记本页需复核。

## 政策页

- 配送说明：配送地区、时效、运费规则、追踪方式。
- 退换货政策：期限、条件、流程、费用承担、联系方式。
- 隐私政策：收集哪些数据、用途、第三方（支付、统计、聊天组件）、联系方式。
- 联系方式：可用的邮箱或客服入口，与客服大师的实际渠道一致。
- 条款、税费说明按市场需要补充。政策文本为草稿时标注“需用户或法律顾问确认”。

## 移动端与性能

- 在窄屏下文字可读、按钮可点、无横向滚动、图片不变形。
- 首屏图片经过压缩，主要内容不依赖悬停才能看到。

## 链接与表单

- 所有内外链可打开、指向正确对象；不含失效、示例或本地地址。
- 表单有必填提示和错误提示；提交后有明确结果；只用测试数据测试。
- 表单与聊天组件的数据去向与隐私政策一致。

## 无障碍基础

- 图片有替代文本；文字与背景对比清晰；表单字段有标签。
- 可用键盘到达主要按钮和链接；不只靠颜色传达信息。

## 上线前验收

逐项填写状态（共用约定原词）：已确认成功 / 失败 / 结果未知 / 未执行 / 待验证，并注明证据（工具返回、回读、实际打开）。

| 项目 | 层级 |
|---|---|
| 页面方案经用户审阅 | 页面方案 |
| 本地文件完整、无占位内容 | 本地候选 |
| 预览链接由工具返回且可打开 | 可访问预览 |
| 正式链接/版本回读确认 | 已部署网站 |
| 政策页上线并可达 | 已部署网站 |
| 收款方式已启用 | 可交易店铺 |
| 配送区域与运费已配置 | 可交易店铺 |
| 税务设置已按市场核对 | 可交易店铺 |
| 测试订单进入后台（经批准或测试模式） | 可交易店铺 |
| 客服入口与人工负责人已就绪（与客服大师的实际渠道一致） | 可交易店铺 |

只有“可交易店铺”各项均为已确认成功，才可表述为店铺可以接单。
