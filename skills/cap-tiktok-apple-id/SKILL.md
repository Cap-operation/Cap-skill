# 美国 Apple ID

## 工作方式

由课前准备入口发起（课前准备上下文）时，先读取 [课前准备流程控制契约](../cap-tiktok-prep/SKILL.md#流程控制契约全局硬规则)，继承当前步骤、状态和待返回位置。跳过、临时答疑、前置阻塞及结束条件按课前准备入口执行；缺少该依赖时不猜测控制规则、不继续顺序陪跑。模块内按现有 SOP 的独立结果建立固定节点编号，不能用“跳过”一次略过整套流程。

单独使用、没有课前上下文时，不套用课程 P 节点流程、跳过规则和结束祝词，只回答美国 Apple ID 与下载 Shadowrocket；本模块以外的问题简短说明不在本模块范围，交回[总入口](../cap-skill/SKILL.md)。单独使用时按[共用交接约定第 9 节“全程引导”](../cap-skill/references/shared-contracts.md#9-全程引导)带用户：每次留一个出口、卡住先诊断、会用的走快速模式。

默认由学员自己注册。按 [references/apple-id-shadowrocket.md](references/apple-id-shadowrocket.md)（依据飞书「1.6 纯正美区本土APPLE ID 注册」）一次指导一个动作，每个关键页面截图确认。

## 关键流程

开始前确认（已抹掉/刷机、无 SIM 卡、English + United States、按路线定网络）→ 设置顶部 Apple Account → Don't have an Apple Account → Adult → 姓名生日 → 创建 iCloud 邮箱 → 密码 → SMSPool 美国号码短信验证 → Agree → 绑定本人 +86 受信任号码 → App Store Review → United States → None → 账单地址 → 礼品卡 → Shadowrocket。

- 网络按路线分：软路由路线照飞书 1.6，手机连美国 IP 的 Wi-Fi，`whoer.net` 显示美国再注册；小火箭路线（课程默认）注册时还没有小火箭和美国 IP，用自家 Wi-Fi 注册，不要求 `whoer.net` 显示美国。飞书没写这种情况，按页面选 United States；这条路线的验收是 Review 页显示 `United States` 的截图。
- 手机号验证按飞书用 SMSPool 租的美国号码，到那一步再租；租号要花钱，先按[总入口硬规则 10](../cap-skill/SKILL.md) 说清楚价格以页面为准、由学员本人付款；注册完马上绑本人 +86 号码，否则号码过期后收不到验证码。
- 账单地址用学员自己能对应的真实美国地址，最好在不收销售税的州（收税州 3 美金扣不够）。AI 不提供现成地址、不代找、不编地址；学员没有能对应的地址时转【船长电商】工作人员。
- 租号、买卡要花钱，先说清楚、由学员自己付款。不索取密码、验证码、兑换码、恢复码和地址；不用共享账号或虚构资料。
- 飞书没写的卡点（如兑换报错）查 Apple 官方资料并写明依据；学员同一步第二次还卡指到飞书 1.6 对应段落，第三次转【船长电商】工作人员（在社交媒体上搜索“船长电商”）。
