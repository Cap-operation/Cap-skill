# 钩子方法

用于环节 4（开头钩子设计）和环节 5 中的承接检查。这里是写作方法与 AI 建议，不是平台规则，也不保证播放或转化。

## 1. 先定人群和动机，再写句子

顺序：**人群情境 → 单一动机 → 表现形式 → 钩子**。

| 动机类型 | 观众心里的话 | 需要的事实 |
|---|---|---|
| 痛点 | “这个问题一直烦我” | 产品确实解决该问题的规格或演示 |
| 愿望 | “我想要更好的状态/结果” | 可兑现的具体结果及条件 |
| 疑虑 | “会不会不好用/不值” | 能回应疑虑的证据：材质、尺寸、退换、实测 |
| 场景 | “我也会遇到这个时刻” | 产品在该场景的真实用法 |
| 比较 | “到底选哪个” | 真实可比的对象和差异，不贬低未核实的竞品 |

一个钩子只承载一个动机。多版本应在人群、动机或形式上不同，而不是换同义词。

## 2. 钩子的三个部分

| 部分 | 作用 | 交付方式 |
|---|---|---|
| 首句口播 | 提出问题、期待或冲突，是主要改写对象 | 必给 |
| 开场标题 | 静音浏览时让人一眼看懂主张，可与口播互补而不必逐字重复 | 默认给，10–16 字内为宜 |
| 开场画面 | 让人停下来看 | 仅给一行可选拍摄提示；不调用媒体生成 |

开场标题与逐字字幕不同：逐字字幕必须与口播一致，不受“标题不重复口播”的限制。

## 3. 形式选择库

只选与事实相符的形式。右列是使用前提，缺少前提就不用。

| 形式 | 示意（占位） | 使用前提 |
|---|---|---|
| 具体场景 | “早上赶时间，头发还一直炸？” | 场景真实对应产品用途 |
| 直接提问 | “你的保温杯是不是半天就凉？” | 正文回答该问题 |
| 具体主张 | “这款杯子装热水 6 小时还烫手” | 主张有自己产品的实测或规格依据 |
| 演示先行 | “先看这一下——” | 有可拍的真实演示 |
| 前后对比 | “左边是用之前，右边是用之后” | 自己产品真实拍摄的前后，非借用 |
| 新旧比较 | “以前我用 A，现在换成 B 的原因” | 第一人称只用于用户本人真实经历 |
| 二选一 | “X 和 Y，你会选哪个？” | 两个选项都真实存在且比较公平 |
| 打破误区 | “很多人以为……其实……” | “其实”部分有证据，不制造虚假争议 |
| 清单/数字 | “买之前先看这 3 点” | 清单内容正文全部兑现 |
| 悬念 | “最后一个细节最关键” | 结尾确实给出该细节 |
| 证据先行 | “这是我们自己测的数据：……” | 有自己的数据、样本与条件 |
| 亲历自述 | “我用了两周……” | 只用用户本人或授权达人的真实经历 |

禁用：编造数字、借用他人亲历或证言、虚构库存/倒计时/折扣、“全网最低”“百分百有效”等无法证明的绝对承诺。

## 4. 承接：钩子后约 3–15 秒

承接段要直接回应开头：钩子问了什么，承接就开始回答；钩子展示了什么场景，承接就推进该场景。常见断裂：

- 钩子问原因，正文先讲品牌故事。
- 钩子承诺结果，正文没有展示结果或条件。
- 钩子是悬念，正文结尾没揭晓。

每个新钩子配一句或一小段承接。用户只要求换首句时，保持正文，单列“承接是否需要调整”的最小建议。

钩子和承接一起改时，在测试记录中算同一个测试单元，不能把结果差异全部归因于第一句。

## 5. 参考钩子的复用方式

学习参考钩子的**机制**（动机＋形式＋节奏），不照抄句子。替换时按事实账逐项检查：机制里依赖的数字、经历、对比对象在自己产品上是否成立；不成立就换形式，而不是硬套。
