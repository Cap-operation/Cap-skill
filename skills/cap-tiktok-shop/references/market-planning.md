# 市场与店铺模式选择

核对日期：2026-09-17。用于营业执照和注册之前确定目标市场、店铺模式与履约方式。用户没说市场时默认按美国（北美）讲，课程推荐先看北美、南美。本篇后面的营业执照、注册、保证金、物流步骤来自课程资料，是按中国大陆主体的东南亚跨境自运营店写的；美国等其他市场、本土店和全托管的准入、费用和流程需核对当前官方规则，不直接套用。

## 只确认四项

读取用户已有信息，缺少时只问会改变路径的问题，一次一个：

1. 计划销售的国家；
2. 主体注册地和已有营业执照类型；
3. 自己运营还是全托管（见下方对比表）；
4. 使用中国直发，还是已经在目标国备货。

## 新手说“不知道”“你定”时

这是做决定卡住，不要截图，直接给下面三个选项，标出推荐项。这是课程方法（船长电商推荐先看北美、南美），不代表一定能开通；准入、入驻方式、类目和费用需核对当前官方规则。

| 国家 | 一句话理由 |
|---|---|
| 美国（北美，推荐） | 市场最大、用英语，内容和客服门槛低。要先知道：中国主体开美国跨境店只收公司（个体户不行）、要从美国本地仓发货（不能中国直发）、每店保证金 1500 美元（官方 2026-11-21 核对，见[美国市场开店](us-market.md)） |
| 墨西哥（南美方向，拉美西语市场） | 用西班牙语，离美国近，适合想做拉美、身边能找到西语帮手的人 |
| 巴西（南美） | 人口多、用葡萄牙语；税务和清关比较复杂，需要先把成本算清楚再决定 |

用户说“你定”：按推荐项往下走，并告诉他“之后随时可以换，换国家只影响注册时选的站点和后面的合规核对”。选美国时把上表“要先知道”的三点（公司、美国本地发货、保证金）用白话说清，保证金按总入口硬规则 10 写清币种和约合人民币，用户知道这些后再往下走。

选了北美、南美的国家时要说清楚：本篇后面的营业执照、注册、保证金、物流步骤是按东南亚跨境店写的，进入这些步骤前，先核对该国当前的官方入驻要求（是否接受中国大陆主体的跨境店、是否需要当地公司或仓库），不直接套用东南亚的做法。学员做美国时，课程做法在飞书知识库第 5 章（见[飞书知识库章节对照](../../cap-skill/references/feishu-map.md)），官方要点见 [美国市场开店（官方依据）](us-market.md)。

## 选择顺序

1. 先查目标市场是否对当前主体和店铺模式开放；
2. 再查主营类目是否允许销售，是否需要定邀、认证或许可；
3. 核对结算、保证金、物流、退货和语言能力；
4. 粗看目标类目在该国的大致价格带。这时还没有具体商品，不要求算完整贡献利润；利润在选品和拿样后按 [利润口径](../../cap-skill/references/profit.md) 算；
5. 最后确定一个首发市场、一个店铺模式和一个履约方式。

新手不要同时开多个市场。先跑通一个市场的上架、内容、订单、发货和退款，再评估复制。

## 自运营还是全托管

下表是课程整理的大致分工，结论需核对：全托管的招商、供货、定价和履约规则以 TikTok Shop 官方招商页和卖家大学里“全托管”的当前说明为准。

| | 跨境自运营 | 全托管 |
|---|---|---|
| 选品、上架 | 自己 | 自己报品、供货，平台审核 |
| 定价 | 自己定售价 | 自己报供货价，售价主要由平台定 |
| 内容、达人、广告 | 自己做 | 平台主要负责 |
| 发货、售后 | 自己发货、自己处理售后 | 按要求送到平台指定仓，后续履约和售后平台为主 |
| 适合谁 | 想自己做内容、自己控价的人 | 有工厂或稳定货源、不想做内容运营的人 |

本篇后续阶段按跨境自运营写。用户选全托管时，用本表帮他做决定，后续按官方全托管规则走，本系统不提供全托管的分步流程；不把自运营的步骤套到全托管上。

本土店：先核对当地公司、税务、仓库、银行和负责人要求，不用中国跨境店资料替代。

## 已知限制（需核对）

- **印尼**：跨境店的准入和经营方式近几年变化较大，中国跨境卖家现在能不能开、怎么开，以当前官方入驻页为准；没核对前不作为首发推荐。
- **东南亚低值进口税**：多个东南亚国家对低价值进口商品开始征税或调整免税额度，会影响中国直发的到手价和利润。算利润时“税费”一项按目标国当前规则填，不确定就写“未知”，不填 0。

## 市场筛选表

| 维度 | 必查内容 |
|---|---|
| 准入 | 主体、店铺模式、类目和邀请要求 |
| 需求 | 搜索、成交、内容和季节趋势 |
| 竞争 | 价格、头部集中、达人和同质化 |
| 履约 | 直发/海外仓、运费、时效和退货 |
| 合规 | 禁限售、认证、标签和知识产权 |
| 经营 | 语言、客服、结算、汇率和税费 |
