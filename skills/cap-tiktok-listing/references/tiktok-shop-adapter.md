# TikTok Shop 适配（原生路径）

## 当前状态

本包**没有实现** TikTok Shop 原生商品发布适配器，也没有核实可用的第三方发布工具。DSers 推送选项中的 `tiktok` 销售渠道不是 TikTok Shop 店铺发布，不能用来冒充。

用户要求上架 TikTok Shop 时：

1. 产出下方“TikTok 上架资料包”。
2. 转入 [商品上线指导](../../cap-tiktok-shop/references/product-launch.md)：拿样验品、复核利润、SKU、商品卡、发布字段与前台验收按该文执行，本文不重复。
3. 发布动作状态记为“未执行”，原因写“缺少 TikTok Shop 原生发布适配”；由用户在 Seller Center 自行操作，或待日后接入真实适配器。
4. 用户回报已发布后，按审阅与结果模板记录后台状态（审核中/已上线/被拒）与前台可售验收，证据来自用户截图或后台导出。

若宿主将来出现 TikTok Shop 商品工具：先按运行时 schema 发现能力与权限，单独做适配说明和联调，不沿用 DSers 的参数或状态语义。

## TikTok 上架资料包

按 SKU 级别整理，字段名是 Cap 内部约定，不是 TikTok API 字段；具体必填项以目标市场当前后台为准。

| 部分 | 内容 | 来源/核对 |
|---|---|---|
| 基本信息 | 市场、店铺 ID、语言、币种、事实版本 | 共用项目与商品事实 |
| 类目与品牌 | 建议类目路径、品牌状态/授权 | 后台规则；不选相似类目规避资质 |
| 标题 | 商品是什么 + 关键属性 + 用途；目标市场语言 | 共用商品事实，禁夸大与未授权品牌 |
| 图片与视频 | 主图、细节、尺寸、场景、SKU 图；视频角度 | 与实物一致，去水印与他平台标识 |
| 详情 | 问题 → 卖点 → 用法 → 规格清单 → 注意事项 | 有证据的卖点；缺证据列为缺口 |
| 属性 | 必填与推荐属性、材质、尺寸、适配范围 | 样品实测 |
| 变体/SKU | 规格维度、SKU 名、卖家 SKU、对应图片 | 与成本、重量、库存一一对应 |
| 价格 | 日常价、活动最低价、保本价、币种 | 共用利润；未知成本保持未知 |
| 库存 | 首批数量、仓库映射、补货周期 | 真实可履约，不填虚假库存 |
| 物流 | 包装后重量、三边尺寸、物流/运费模板、发货时效 | 实测与后台模板 |
| 售后 | 退货地址、退换政策 | 店铺设置 |
| 合规资料 | 资质、认证、检测报告、标签、电池/液体等运输声明 | 选品与商品合规结果；资料不齐不发布 |
| ID 映射 | 供应商商品/SKU ↔ 内部商品 ↔ TikTok 商品/SKU（发布后回填） | 共用映射约定，不按同名关联 |
| 缺口清单 | 尚缺的资料、证据和待确认项 | — |

资料包交付层级为“草案”或“准备好”；没有后台回读证据前，不写“已上架”。
