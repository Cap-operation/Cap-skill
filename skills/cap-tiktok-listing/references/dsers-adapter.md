# DSers 适配（独立站路径）

用于宿主已安装 DSers MCP Product、目标为 DSers 已连接的 Shopify/Wix 店铺时。本包只提供编排规则，不含 DSers 运行层。

## 安装与连接

- 由用户或维护者按上游说明**单独安装**并在宿主注册为 MCP 服务；固定到已核对的版本，不自动拉取最新。
- 不复制任何人的本机运行目录（如 `.runtime`）、`node_modules`、会话/凭据文件、任务存储或个人登录启动脚本与绝对路径。
- 登录走上游的官方网页流程；不在聊天中收集账号密码。上游存在终端密码回退和明文会话缓存等路径，优先使用浏览器登录；“已保存凭据”不等于会话有效，以后续只读发现为准。
- 认证错误：停止循环，提示重新登录；不反复调用写入工具。

## 运行时发现

每次会话按当前工具列表与输入 schema 确认能力：工具名、参数名、枚举、布尔与 JSON 字符串格式都以实际 schema 为准。下表名称为 **v1.3.3 观察值，必须重新核对**；名称变化时按角色匹配，找不到对应角色即视为缺能力。

上游另注册的流程提示（快速导入、批量导入等）只是模板，不是额外执行能力。

## 按角色的副作用表

| 角色 | v1.3.3 观察名称 | 读/写 | 副作用与注意 |
|---|---|---|---|
| 发现店铺与规则能力 | `dsers_store_discover` | 读 | 返回店铺 ID、平台、规则能力；店铺定价规则查询可能超时为空，不代表店铺未开定价规则 |
| 规则预检 | `dsers_rules_validate` | 读 | 未知或不支持的字段多为 warning 后忽略，不等于生效 |
| 导入商品 | `dsers_product_import` | **云端写** | 在 DSers 导入列表创建/复用商品；带规则时立即尝试保存草稿，保存失败只给 warning；默认市场与可见性不可静默沿用；批量摘要可能丢 warning |
| 预览 | `dsers_product_preview` | 读，**可能云端写** | 通常读本地快照，不代表供应商实时价/库存；恢复路径可能重新抓取并回写 DSers |
| 更新规则 | `dsers_product_update_rules` | **云端写** | 从原始草稿重算并保存到 DSers；整组替换/字段合并语义见 SKILL 第 4 步；保存失败只给 warning；可能覆盖后台人工改动 |
| 设置可见性 | `dsers_product_visibility` | 本地 | 只改后续推送意图，不改已推送商品 |
| 推送店铺 | `dsers_store_push` | **店铺写 + 账户写** | 推送前会再次保存草稿；**可能修改账户物流配置**（如启用原本关闭的供应商物流）；可能只返回“已请求”；无幂等保护，重复调用可能重复上架；批量外层计数不代表逐项成功；`force_push` 仅跳过部分拦截 |
| 查询任务 | `dsers_job_status` | 读本地 | 只读上游本地任务记录，不刷新 DSers 或店铺；多店历史不完整 |
| 删除导入项 | `dsers_product_delete` | **云端删除** | 只删 DSers 导入列表项，已推送的店铺商品仍在；不可恢复，需明确授权 |

## 调用规则

1. 首先只读发现：账号、店铺真实 ID、平台。目标平台不在 Shopify/Wix 时停止；WooCommerce 只作待验证。
2. 导入、规则更新、可能回写的预览、推送、删除都属于外部写入，必须在审阅单的批准范围内。
3. 参数严格按 schema 类型传值；布尔值不要传字符串（上游观察到非 `"true"` 字符串会被当成 false，或反之被强制为 true）。价格输入单位与内部单位不同，按 schema 描述核对。
4. 发布意图只用可见性参数一处决定（仅后台 / 立即可售），不同时传互相矛盾的发布开关。
5. 推送前：确认采用 DSers 价还是店铺定价规则；列出物流副作用并记录推送前配置；配送模板未匹配会回落默认，需确认。
6. 推送后：逐项读返回状态与 warning；warning 输出可能被截断或限量，不能把“没看到 warning”当全部通过。
7. 结果未知：到目标店铺后台核对，不以 job_status 或再次推送代替；仅对确认未执行的单项补推。
8. 每项保存 `(账号, 导入项 ID, 店铺 ID) → 推送请求/事件 ID → 后台回读证据`，同一组合已请求或已完成时不得盲推。

## 不支持或未验证

- TikTok Shop 原生发布（推送选项中的 `tiktok` 销售渠道不是 TikTok Shop 目标店铺）。
- 图片文字翻译、去 Logo（上游仅占位警告）。
- 上游文档中的部分认证方式与云端 OAuth 入口与本地实现不一致，未纳入本包流程。
- 任何真实账号、店铺、导入或推送均未在本包联调。
