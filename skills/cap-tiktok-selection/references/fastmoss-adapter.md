# FastMoss 适配

FastMoss 是可选的第三方研究数据依赖，只提供证据，不决定采购、不替代合规审查、不证明商品一定盈利。选品判断仍按 [选品评分与流程](scoring-and-flow.md)。

## 不随包分发

- 本包**不包含** FastMoss 的 CLI、二进制、Skill 文档或工具目录。上游 CLI npm 包元数据的 `license` 为 `UNLICENSED`，Skill 文档的独立再分发许可尚未确认。
- 需要时由用户按上游说明自行安装：<https://github.com/FastMoss/cli>。安装 CLI/Skill、登录账号、拥有调用额度是三个独立状态，分别核实。
- 账号凭据、OAuth 令牌和 API Key 属于用户本机状态，不随技能迁移，不在聊天、参数、日志或交付物中出现。已有网页会员不等于拥有 CLI/API 权限或额度。

## 运行时发现

宿主可能以 CLI、上游 Skill 或 MCP 连接器等形式提供 FastMoss，也可能完全没有。不写死调用名，按当前环境发现：

1. 检查当前宿主可见的 FastMoss 能力（命令、Skill 或工具列表）和版本；没有则走下文降级路径。
2. 按上游 Skill/CLI 自身说明确认认证状态；未登录时请用户自行完成登录，不代为输入密钥、不手拼授权链接。
3. 每次远端调用前读取**该工具的实时 schema**，以其必填字段、嵌套、类型、枚举、分页和排序结构为准；不从相似工具或静态目录猜参数。实时 schema 不可得时说明受限，被拒后不硬猜。
4. 遵守上游对客户端元数据、参数文件等的调用要求；使用宿主真实名称和版本，不虚构。

静态工具目录只用于设计和按需导航，不作为运行权威。

## 调用约束

- **市场**：显式传入用户的目标国家/地区，不用工具默认市场替代。
- **ID**：先搜索/详情取得真实对象 ID（商品、店铺、达人、视频、直播），后续用 ID 查询；不以名称或昵称代替。同名商品在不同市场或不同 ID 下视为不同对象。
- **类目**：自然语言类目先用工具解析成类目 ID/路径再查询。
- **时间**：只用该工具 schema 支持的时间表达；榜单只取已完成周期；不同工具的时间字段不互相套用；示例日期不当默认值。
- **范围**：调用前列出本次所需工具、前置解析、分页上限和预期产物；不为“多查一点”无界翻页。

## 每条证据记录

| 字段 | 说明 |
|---|---|
| 来源 | `FastMoss`（多接口合计一个第三方来源）+ 工具名 |
| 对象 ID | 工具返回的真实 ID 与类型 |
| 市场 | 国家/地区 |
| 币种 | 返回值币种；不同币种不直接相加 |
| 窗口 | 起止日期或榜单周期，及时区（如返回） |
| 筛选与排序 | 实际传入的条件 |
| 分页覆盖 | 已取页数/条数、是否完整；截断时注明 |
| 取数时间 | 本次调用时间 |
| 数据性质 | 第三方估值；非官方结算 |

GMV、销量为第三方估算，不是利润或自店实数；单视频/单场直播数据不代表商品整体成交。交叉验证需另一独立来源或官方趋势。

## 失败处理

所有失败**有界停止**：保留已成功取得的证据，说明哪一步失败、影响哪些结论，给一条针对性修复建议。

| 情况 | 处理 |
|---|---|
| 未安装 / 宿主不可见 | 说明是可选依赖及上游链接；改用官方数据或用户导出资料 |
| 认证失败 / 未登录 | 请用户按上游说明自行登录；不循环发起登录，不索取密钥 |
| 额度不足 | 告知需用户自行核实额度；不自动充值、不购买、不重复调用 |
| 参数错误 | 重读该工具实时 schema 修正一次；缺必填输入时问一个聚焦问题；不臆造字段 |
| 空结果 | 提出一两个具体的放宽或修正条件 |
| 超时 / 未知错误 | 不盲目重试（可能已计费）；标记该项未取得 |

不能确定的计费规则、限流和重试语义不自行推断为“免费”或“可无限重试”。

## 降级路径

无 FastMoss 时仍可完成：

- 基于 TikTok 官方后台、Creative Center、搜索分析的数据（用户提供截图、导出或文字）；
- 用户提供的 FastMoss/其他工具导出表（记录导出时间、市场、窗口）；
- 方法层面的候选筛选框架、硬性淘汰清单、利润测算模板和证据缺口清单。

此时明确标注“未取得实时第三方数据”，不编造实时数字、排名或趋势。
