# 跨境电商检查清单

只列跨境独立站最常见、影响最大的项目。每项写“现状 → 改法 → 谁来改”。

## 1. 能不能被抓到（SEO 与 GEO 的共同基础）

| 检查 | 合格标准 | 谁来改 |
|---|---|---|
| robots.txt | 不屏蔽商品页、分类页；对 GPTBot、PerplexityBot、Google-Extended、ClaudeBot 等 AI 爬虫的放行或屏蔽是用户有意选择 | 建站大师 / 用户 |
| sitemap.xml | 存在、包含全部在售商品、已在 Search Console 提交 | 建站大师 / 用户 |
| 收录 | 主推商品页能被搜索引擎收录；没有误加 noindex | 建站大师 |
| 页面速度与手机端 | 手机打开主推商品页不卡顿；首屏能看到价格和购买按钮 | 建站大师 |
| 内容是否依赖脚本 | 商品名、价格、描述在页面源码里能直接看到，不是全靠前端脚本加载 | 建站大师 |

## 2. 商品页

| 检查 | 合格标准 | 谁来改 |
|---|---|---|
| 标题 | 用目标国家买家会搜的说法写，包含品类词和关键属性；不堆关键词 | 上架大师 |
| 描述 | 先回答买家最关心的 3 个问题（解决什么、尺寸材质、发货退货），每段能单独被引用 | 上架大师 |
| 图片 | 每张有描述性 alt 文字；体积已压缩 | 上架大师 |
| Product 结构化数据 | 含名称、图片、品牌、价格、币种、库存状态；有真实评价时才加评分 | 建站大师 |
| FAQ | 3–5 个真实买家问题与简短回答，可来自客服回流 | 客服大师提供素材，上架大师写入 |
| 政策页 | 运费、退货、联系方式清楚可找；与商品页承诺一致 | 建站大师 |

## 3. 多国家、多语言

| 检查 | 合格标准 |
|---|---|
| 网址结构 | 每个国家或语言有固定网址（子目录或子域名），不只靠自动跳转 |
| hreflang | 每个语言版本互相标注，并有 x-default |
| 币种与价格 | 每个国家页面显示当地币种，结构化数据的币种与页面一致 |
| 翻译 | 不是机器直译；尺码、单位、节日、支付方式按当地习惯 |

## 4. 被 AI 推荐（GEO）

| 检查 | 合格标准 |
|---|---|
| 可引用段落 | 关键页面有 40–80 字、能单独回答一个问题的段落（如“XX 适合什么人”“和 YY 有什么不同”） |
| 品牌信息 | 关于我们页写清品牌是谁、做什么、在哪里发货；各页面品牌名写法一致 |
| 组织结构化数据 | Organization 含名称、Logo、官网、社媒主页链接（sameAs） |
| llms.txt | 网站根目录有一份简短的站点说明和重点页面清单（可选，新兴做法，不保证被采用） |
| 站外提及 | 品牌在 Reddit、YouTube、测评站、行业媒体有真实讨论；没有时给合规的补强建议（真实测评合作、达人内容），不刷帖 |
| 对比与选购内容 | 有“怎么选”“A 和 B 对比”类真实内容，信息有来源 |

## 5. 交付顺序

1. 能不能被抓到（不通过时，其他都白做）；
2. 主推商品页；
3. 多国家设置（多国站点才做）；
4. GEO。

每次只推进当前最靠前的一层，给出前三件事，不一次铺开全部清单。
