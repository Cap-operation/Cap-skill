# IP 购买规格

## 服务商选择

- 东南亚地区：优先 `911Proxy`。
- 欧美地区：优先 `Miya` 或 `IPRoyal`。

## 下单前核对

- 目标国家/地区；
- 州、省或城市；
- 静态住宅或 ISP 类型；
- ASN 类型；
- 独享；
- IP 数量；
- 有效期；
- 协议、端口、认证方式和异常更换规则。

优先目标地区匹配、长期稳定、独享的静态住宅或 ISP IP。出现 `Hosting`、`Datacenter`、`Cloud` 或 `VPS` 时，先确认是否选错产品。

## 询价

IP 是网络出口的地址标识。购买或更换 IP 时，不能承诺某个号段一定能解决平台问题。让用户向服务商确认：类型（家庭/数据中心/移动等）、国家/地区、城市级别、独享/共享、静态/动态、会话时长、带宽、并发、历史滥用处理和更换规则。

可用的询价表达：

```text
我需要【国家/地区】【类型】【静态/动态】【独享/共享】【数量/并发】
请确认：出口位置、ASN/网络类型、会话保持、带宽、有效期、测试方式、异常更换规则。
```

## 各渠道下单步骤

以下内容根据学员提供的购买页面截图整理。价格、库存、页面名称和可选地区会变化，购买时以服务商当前页面为准。截图只用于确认入口和筛选逻辑，不代表固定价格或固定库存。

### Miya：美国静态住宅代理

截图显示的入口和筛选方式：

1. 进入 **静态住宅代理**。
2. 选择套餐周期，例如图中的 **30 天**。
3. 选择 **独享住宅 ISP** 类别。
4. 在地区中选择 **美国**。
5. 根据目标城市和服务要求选择运营商/ISP。截图中可见美国选项及 Verizon 等运营商选项。
6. 确认 IP 数量、周期和订单金额后再购买。

当前业务口径是优先选择目标地区匹配、长期稳定、独享的静态住宅 IP。是否属于真正 ISP、是否能指定城市、是否可更换，必须在下单前向服务商确认。

### IPRoyal：ISP

截图显示的入口：

1. 在左侧代理产品中选择 **ISP**。
2. 点击 ISP 产品的 **现在购买**。
3. 购买前确认国家/地区、州/城市、ASN、IP 数量、有效期、会话保持和更换规则。
4. 如果页面同时提供住宅代理、ISP 和 Datacenter，不要混选；先按任务要求确认使用的是 ISP 产品。

IPRoyal 页面同时展示住宅代理、ISP、Datacenter、Mobile 等不同类型。不能因为都写着“代理”就把它们当成同一种 IP。

### 911Proxy：静态住宅代理

截图显示的入口和筛选方式：

1. 进入 **静态住宅代理**。
2. 在国家/地区中选择目标位置。
3. 按需要选择 ASN。截图示例选择的是 **马来西亚**，ASN 为 `U Mobile Sdn Bhd (38466)`，数量为 1 IP。
4. 确认单价、有效期和 IP 数量后购买。

截图中的地区是马来西亚，不代表美国购买流程；如果目标是美国，必须在国家/地区列表中选择美国，再根据可用 ASN 和城市要求筛选。下单前确认该 IP 是否独享、静态、长期保持同一出口，以及是否支持当前客户端。

### 购买时的统一询问话术

```text
我需要【国家/地区】【州/城市】【静态住宅或 ISP】【独享】【1 个 IP】【有效期】。
请确认：具体 ASN/运营商、城市级定位、是否长期固定、是否共享、协议支持、
端口和认证方式、异常更换规则，以及是否适合手机端 Shadowrocket 使用。
```

不要只对服务商说“我要一个干净 IP”。“干净”必须拆成可核验条件：类型、国家/城市、ASN、独享状态、固定时长、风险检测结果和售后更换规则。

## 购买后

服务商通常提供 `Address`、`Port`、`Username`、`Password` 和协议类型。只确认字段是否齐全，不要求把完整参数发给 AI。质量检测由 `cap-tiktok-ip-diagnostics` 负责。
