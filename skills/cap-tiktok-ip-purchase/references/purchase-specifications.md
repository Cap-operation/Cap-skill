# IP 购买规格

## 服务商选择

依据：飞书 1.5「基础版IP配置流程」（软路由版和小火箭版两节写法相同）的「IP购买渠道」。

- 东南亚地区：优先 `911Proxy`（https://www.911proxy.com）。
- 欧美地区：优先 `IPRoyal`（https://iproyal.com）或 `Miya`（https://miyaip.com）。
- IPRoyal 下单时的额外需求：要真实 ISP-ASN，飞书举的运营商是 Comcast、AT&T、Spectrum、Verizon。

## 下单前核对

这份清单给用户付款前对照订单页用，不是开场逐项提问；开场只问目标国家，其余按 SKILL.md 的默认推荐。

- 目标国家/地区；
- 州、省或城市；
- 静态住宅或 ISP 类型；
- ASN 类型；
- 独享；
- IP 数量；
- 有效期；
- 协议、端口、认证方式和异常更换规则。

优先目标地区匹配、长期稳定、独享的静态住宅或 ISP IP。出现 `Hosting`、`Datacenter`、`Cloud` 或 `VPS` 时，先确认是否选错产品。

## 询价

IP 是网络出口的地址标识。购买或更换 IP 时，不能承诺某个号段一定能解决平台问题。让用户向服务商确认：类型（家庭/数据中心/移动等）、国家/地区、城市级别、独享/共享、静态/动态、会话时长、带宽、并发、历史滥用处理和更换规则。

可用的询价表达：

```text
我需要【国家/地区】【类型】【静态/动态】【独享/共享】【数量/并发】
请确认：出口位置、ASN/网络类型、会话保持、带宽、有效期、测试方式、异常更换规则。
```

## 各渠道下单步骤

价格、库存、页面名称和可选地区会变化，购买时以服务商当前页面为准。不在回复里报具体价格，让用户看页面金额。

### IPRoyal：ISP（飞书有截图，按这个带）

1. 电脑连上粉猫，用 Chrome 打开 IPRoyal，右上角语言选中文，用 Google 账号登录。
2. 主页（或左侧“代理”下的 **ISP**）点 ISP 卡片的 **现在购买**。页面上住宅代理、ISP、Datacenter、Mobile 是不同产品，不要混选。
3. 订单页（Create ISP Dedicated order）四块，飞书截图的选法：
   - **1. Select subscription plan**：周期选 30 Days，数量 1 个 Proxy。
   - **2. Choose location**：Proxy location 选目标国家（截图是 United States），Quantity 1；Add City/State 是可选项。
   - **3. Choose fraud score**：截图选的是 **Premium**（低欺诈分档，会加价）；选哪档、加多少钱以页面为准，先让用户看清再决定。
   - **4. Extras**：勾选 **Add extra requirements**，在建议标签里点 **Fresh/Non-Recycled IP**，输入框写 `never used on Tiktok`；欧美再按上面的额外需求要真实 ISP-ASN。这一项也会加价，以页面为准。截图里另外两个选项（多设备访问、每次续费换新 IP）没有勾。
4. 右侧 Summary 看清最终金额，用户本人点 Continue 付款。
5. 付款后左侧 **我的订单** → 这笔订单 → **代理详情**：列表里是 主持人（IP 地址）、端口、用户名、密码；下面 **协议** 从 HTTP 改成 **SOCKS5**，格式 `HOST:PORT:USER:PASS`。完成：协议栏显示 SOCKS5。

### Miya、911Proxy

飞书 1.5 对这两家只给了渠道名和网址（欧美可选 Miya https://miyaip.com ，东南亚优先 911Proxy https://www.911proxy.com ），没有截图和下单步骤，这里也不写具体按钮。做法只有三步：

1. 进官网，选静态住宅或 ISP 类产品（页面上的叫法以官网为准，不选数据中心、机房类）。
2. 按上面的“下单前核对”逐项看：国家/地区、城市、类型、ASN、是否独享、数量、有效期、协议（要能用 Socks5）和更换规则。页面上看不出来的，用下面的询问话术问服务商。
3. 付款前按[总入口硬规则 10](../../cap-skill/SKILL.md) 说清楚这单花多少钱、是一次性还是按周期续费、怎么停止续费，都以页面为准；用户本人付款。

看不懂页面就请学员发打码截图，或转【船长电商】工作人员，不按印象补写按钮。

### 购买时的统一询问话术

```text
我需要【国家/地区】【州/城市】【静态住宅或 ISP】【独享】【1 个 IP】【有效期】。
请确认：具体 ASN/运营商、城市级定位、是否长期固定、是否共享、协议支持、
端口和认证方式、异常更换规则，以及是否适合手机端 Shadowrocket 使用。
```

不要只对服务商说“我要一个干净 IP”。“干净”必须拆成可核验条件：类型、国家/城市、ASN、独享状态、固定时长、风险检测结果和售后更换规则。

## 购买后

服务商通常提供 `Address`、`Port`、`Username`、`Password` 和协议类型；课程里小火箭和软路由都按 **Socks5** 填，所以协议要先在订单详情里改成 Socks5。只确认字段是否齐全，不要求把完整参数发给 AI；截图验收时用户名、密码要打码。质量检测由 `cap-tiktok-ip-diagnostics` 负责。

## 软路由版

飞书 1.5「基础版IP配置流程（软路由版）」用的是同一套购买渠道和同一个 IPRoyal 下单流程，买完把 IP 填进软路由 PassWall2 的节点（类型 singbox、协议 Socks5），再给每台手机设内网固定地址。本技能包没有软路由配置模块：只帮用户把 IP 买对、协议改成 Socks5；路由器和手机网络设置指到飞书那一节，卡住转【船长电商】工作人员。
