# TikTok 运营阶段与实时资料机制

## 目标

基础设备、网络和 IP 配置完成后，进入 TikTok 运营阶段。这个阶段不要求另行建立一套固定运营教程，用户遇到运营问题时只走两条路径：

1. 直接联系【船长电商】工作人员提问；
2. 由 AI 根据用户的问题、截图和最新可靠资料进行查询并答复。

这两条路径同样适用于真实故障处理。AI 负责先判断问题、收集必要证据和给出下一步；需要业务判断、账号处理或人工确认时，告知用户联系【船长电商】工作人员。

运营阶段可以协助处理：

- 下载和注册 TikTok、账号底子自查、推荐页刷出中文、美区个人号橱窗资格页（课程有做法，见下面“课程做法”）；
- 账号登录和基础资料设置；
- 头像、昵称、用户名、隐私和账号类型；
- 浏览、搜索、收藏、关注、点赞等基础功能；
- 发作品、作品可见性、审核和推荐资格；
- 0 播放、无法互动、无法换头像等现象的证据化诊断；
- 根据用户截图和官方规则，给出可执行的下一步。

本阶段不承诺播放量、解封、恢复互动或进入推荐，也不协助刷量、批量养号、伪造身份地区、操纵互动或规避平台风控。

定位、后台刷新等手机设置的课程做法在飞书「1.3 设备刷机与深度环境伪装指引」方案 B 的图文里，归[手机设备初始化](../../cap-tiktok-device-reset/SKILL.md)带；本模块不另给一套。用户问具体某个开关该开还是关时，请他回到那个模块，或（学员）看飞书 1.3 那一段；不凭经验给固定的开关组合。

## 课程做法（飞书第 1 章）

下面四件事飞书里有课程做法，按飞书带，不另换一套。一次只带一步：说清在画面上找什么、什么算完成，请用户发打码截图确认再走下一步。同一步第二次卡住，按[飞书章节对照](../../cap-skill/references/feishu-map.md)附上对应那一节（只对学员发链接）；第三次请他联系【船长电商】工作人员。密码、验证码、邮箱取件链接不发给 AI。

页面上的英文按钮名来自飞书截图，版本更新后可能变；对不上时请用户发当前页面截图，按截图判断。

### 下载 TikTok（飞书 1.8「下载流程」）

前提：手机已经按[手机设备初始化](../../cap-tiktok-device-reset/SKILL.md)刷好、设置好。下载这一步不用开小火箭，连自家 Wi-Fi 就行。登录用的是用户自己按[美国 Apple ID](../../cap-tiktok-apple-id/SKILL.md)注册的美区 Apple ID；还没有就先去那个模块，不用别人的或共享的 Apple ID：这个 ID 要长期自己控制，共享或买来的 ID 有被锁、被原主收回的风险（和 Apple ID 模块同一口径）。飞书 1.8 写的“闲鱼买美区 Apple ID、共享 ID 渠道”不用。

1. 打开 App Store。弹出「Personalised Ads」时，点下面的「Turn Off Personalised Ads」。完成：进到 App Store 首页（Today）。
2. 点右上角头像，用美区 Apple ID 登录，密码和验证码自己输。完成：头像页显示这个 Apple ID 的名字和邮箱。
3. 点右下角 Search，搜 TikTok，点下载。完成：主屏出现 TikTok 图标。
4. 同样搜 Shadowrocket 下载。在 Apple ID 模块里买过的这里直接下；没买过的回 Apple ID 模块。
5. 同样搜 Outlook 下载，后面收 TikTok 注册验证码用。
下载完不用退出 Apple ID。飞书 1.8 最后让「Sign Out」，是因为它用的是共享或买来的 ID；这里用的是本人注册的 ID，留着登录，以后更新 App 也方便。

### 注册 TikTok（飞书 1.8「注册流程」）

前提：小火箭已连上、[IP 检测](../../cap-tiktok-ip-diagnostics/SKILL.md)已通过，并且打开 TikTok 刷 5–10 条推荐页，看到的是目标国家本地内容（飞书 1.4「阶段四：活环境业务实测」）。刷出中文的，不在这个环境注册，先按下面“推荐页刷出中文”处理。

注册用邮箱。飞书把注册方式分了档（课程经验，不是官方说法）：美国手机卡加美区 Apple ID 最好；其次 Gmail、Outlook、Hotmail、美国域名邮箱；再次其他域名邮箱。课程推荐用 Outlook 邮箱。邮箱要是用户自己能登录、能收验证码的。飞书推荐去网上买现成的 Outlook 邮箱，买的话要花钱，花钱前按[总入口硬规则 10](../../cap-skill/SKILL.md) 说清楚多少钱（以页面为准）、由用户本人付款；也可以用自己已有的邮箱。

1. 打开 TikTok。弹出「Allow "TikTok" to use wireless data?」时选第二个「WLAN Only」。
2. 在登录页最下面点「Sign up」。
3. 选「Use phone or email」。
4. 生日页填账号持有人的真实生日，必须满 18 岁（飞书要求；以后开橱窗的资格页也要求 18 岁以上）。点「Continue」。
5. 切到「Email」，输入邮箱，点「Continue」。
6. 到「Verify email」页后，去 Outlook 找 TikTok 发来的验证码，自己填进去。完成：进到「Create password」页。
7. 按页面列出的要求设密码，自己记在安全的地方，一定要记住，不发给我。
8. 弹出通知权限时按自己需要选，不影响注册。
9. 「Choose your interests」页选和你打算发的内容一致的类目（飞书：选了类目，流量池才能打正）。点「Next」。
10. 完成：进到 For You 推荐页，底部有 Home 和 Profile。请用户发这一页截图验收。

### 账号底子自查（飞书 1.9）

用来查自己的号或交到手上的号是不是云机号、跨区号、刷粉号、投流号。这些号按课程经验稳定性差，到手 3–5 天死号很常见。

1. 查登录记录：Profile → 右上角三条杠 → Activity Center → Account History（入口位置以当前版本为准，找不到请发菜单截图）。逐条看「Account created」「Account logged in」后面写的设备和国家。
   - 出现 Web、三星、Google 这类不是用户手上这台真机的设备：课程判为云机号，不是一机一号。
   - 出现目标市场以外的国家：课程判为跨区号。
   - 完成：创建和登录都来自手上这台手机，国家都是目标市场。
2. 查涨粉：TikTok Studio → Analytics → Content，时间选「365 days」，在「Your top posts」里切到「New followers」，再看粉丝页的画像和来源。
   - 涨粉曲线平滑得像画出来的、没有爆款起伏：刷粉痕迹。
   - 粉丝多是关注很多、几乎不活跃的号：机器刷粉。
   - 涨粉大多不是来自 For You 推荐：投流催熟号。
   - 私信量异常高、评论点赞不自然、内容和互关的主播大量重叠：截流号、互关号。

课程结论（课程经验，不是官方说法）：

- 内容方向（美女号、宠物号、AI 号之类）和账号质量关系弱；从注册起网络、IP、设备是否干净、统一、稳定，关系强。
- 号到手 3 天内死掉，按课程判断是底层环境从一开始就不合格，跟发什么内容无关。
- 黑五这类大促期间投流号偶尔能活，是平台风控相对宽松的窗口，不是号本身好。
- 一台独立设备、一条纯净住宅 ISP 网络、一套极简环境，从注册到起号全程不变；按课程经验通常要 1.5–3 个月才进入稳定的自然流。

查出问题只说明判断依据，不教怎么“洗”记录或换环境掩盖。

### 推荐页刷出中文（飞书 1.4「流量池层级判定与刷出中文」）

课程用推荐页内容判断环境，分三档（课程说法，TikTok 官方没有公布这种分层）：

- 刷出来的多是目标国家本地内容，夹着本地广告和周边直播：环境好，课程的目标状态。
- 能刷出英文，但混着很多非目标国家的内容，几乎没有本地广告：环境一般，课程认为这种播放难转化。
- 刷出中文、老旧搬运、只有个位数点赞的内容：课程认为环境已被识别，账号权重很低。

刷出中文时，先停下，不在这个环境注册或登录主力号。课程的处理顺序，一次只做一步：

1. 彻底卸载 TikTok，重装。
2. 查 DNS 和 WebRTC 有没有漏，交给 [IP 检测](../../cap-tiktok-ip-diagnostics/SKILL.md)。
3. 检测全部通过还刷中文：课程做法是废弃这个节点，换新的原生 ISP 节点，交给 [IP 购买](../../cap-tiktok-ip-purchase/SKILL.md)。
4. 换了节点还不行：重新连电脑刷机，交给[手机设备初始化](../../cap-tiktok-device-reset/SKILL.md)。

0 播放还是按下面“发作品”先区分上传、可见性、审核、推荐资格和账号状态；推荐页明显不是本地内容时，再把这一段纳入排查，不能只凭 0 播放断定是 IP。

### 美区个人号橱窗资格页（飞书 1.10，飞书版本日期 2026-07-06）

适用：个人号、达人号想走 TikTok Shop 创作者带货（Creator Pilot Program 或 Affiliate）。店铺官方号、渠道号在卖家中心绑定后的橱窗归[店铺篇](../../cap-tiktok-shop/SKILL.md)。

飞书的说法：美区 1000 粉可能出现试点入口（Creator Pilot Program），5000 粉是正式 Affiliate 的常见门槛。门槛会变，用户问门槛或依据时按“深问必查”查当天官方资料。入口（Studio 里的 TikTok Shop 按钮、信息流里的 Start、商品卡）只是入口，能不能开看资格页。

查之前先确认（飞书检查前准备）：

- 到粉后等 24–48 小时再看；
- 没有明显的社区规范违规提示，最近 2–3 天作品还有正常播放；
- 最近没有频繁改头像、昵称、简介、生日、绑定信息；
- 用这个号平时稳定的手机和登录方式；
- 只看一次，不连续进出、不反复刷新、不同时点多个入口；
- 看到 X 不马上换设备、网络或登录方式；不为通过审核造假身份、地区、资料，不刷粉刷互动。

识别资格页，一步一项：

1. 用平时这台手机打开 TikTok，从 TikTok Studio 里的 TikTok Shop 按钮或系统推的入口进资格页。截完整页面（用户名打码）发我，截完就退出。
2. 看标题：「Join the Creator Pilot Program」是 1000 粉试点；「Promote products, earn commission」是 5000 粉 Affiliate（风险评估版）；「Earn commission with TikTok Shop Affiliate」是 5000 粉 Affiliate（综合检查版）；其他文案按新版本处理，截图存档，标“未知”。
3. 看粉丝项：「Have 1,000 followers」或「Have over 5000 followers」。粉丝项是 X：粉丝不够或系统还没刷新，24–48 小时后再看。
4. 看第四项：「Must pass account risk evaluation」是风险评估版，审核较轻；「Must pass TikTok Shop and creator account checks」是综合检查版，较严，最容易卡在这一项。版本按第四项分，不按标题分：1000 粉试点也可能出现这一项（飞书叫“1000 粉严格版”），处理同综合检查版。
5. 看按钮：「Join now」或「Apply」红色可点，是现在能加入或申请；灰色是现在不行；没有按钮或页面异常，截图存档。

怎么处理（飞书决策矩阵和观察池）：

- 四项全勾、按钮可点：先过下面“点之前”的检查再点。四项全勾但最近播放有波动：先稳 1–2 天。
- 前三项勾、第四项 X：不是粉丝、年龄、社区规范的问题，号不算废，进观察。7 天看一次，最长 14 天（飞书观察池统一按 7–14 天复查）。
- 粉丝达标但没出现入口：3–7 天后再看。
- 社区规范或年龄项 X：先停 Shop 操作，按下面“故障诊断顺序”查账号状态。
- 观察期间：正常发垂直内容，资料不动，有自然评论正常回，记下播放、互动、粉丝变化；不频繁进 Shop 页面，不反复点 Apply 或 Join now，不换登录环境，不机械刷视频“养号”。

点之前（飞书申请前检查清单），有一项没做到就先不点：页面截图已存；没有违规提示；最近 2–3 天播放没有断崖；资料最近没大改；想好了加入后的内容方向和第一批测试商品；清楚这是试点还是正式 Affiliate。

点之后，在 24 小时、72 小时、7 天各记一次：是否成功进入；有没有商品 marketplace、能不能选品；能不能挂视频商品、能不能直播带货；有没有 showcase（橱窗）；有没有商品数量限制和佣金页面。试点页写明的每周限制（飞书截图里是每周最多 5 条可购物视频、3 场可购物直播）以当前页面为准。

## 深问必查机制

满足以下任一条件时，AI 必须先查询最新、可靠的公开资料，再回答（当前客户端不能联网时，按 [SKILL.md](../SKILL.md) 里“不能联网时”的做法：明说查不了，只给基于截图的初步判断，标“未经官方核实”，给官方帮助中心入口）：

- 用户追问“为什么”“依据是什么”“官方怎么说”；
- 问题涉及账号处罚、内容下架、推荐资格、申诉、商业内容披露或地区功能；
- 规则可能随时间、国家/地区、账号类型或产品版本变化；
- AI 不能从当前截图确定原因；
- 用户连续两轮追问仍不接受初步判断；
- 用户明确要求“详细诊断”“查官方资料”或“给我可靠说法”。

### 资料来源优先级

1. TikTok 官方帮助中心、社区自律规范、账号状态和申诉页面；
2. TikTok 官方创作者或商业资料；
3. Apple、Google、Shadowrocket、IP 服务商等产品官方文档；
4. 监管机构、大学论文或行业研究；
5. 其他资料只能作为背景，不作为单独结论。

回答中必须注明：

```text
查询日期：
资料来源：
适用范围：
官方明确说明：
结合当前截图的判断：
仍然不能确定：
```

如果官方资料没有回答，不得把论坛经验写成官方规则，应明确说“官方资料未能确认”，然后转为补充证据或联系官方支持。

## 运营阶段问诊入口

以下是可选证据池，不是每次必须填写的问卷。先使用已有信息，只索取会改变当前判断的 1–3 项，简单运营咨询不收设备和网络信息；不得为了延长对话逐项盘问：

- 手机型号和 iOS 版本；
- TikTok App 版本；
- 当前 Shadowrocket 是否连接；
- 当前 IP 检测是否通过；
- 问题发生的具体时间；
- TikTok 页面原文或错误提示；
- 相关页面打码截图；
- 这是单个作品、单个功能，还是整个账号都异常。

不要要求发送密码、验证码、完整订阅链接、代理认证参数、恢复码或支付信息。

## 基础操作范围

### 账号和资料

先按 TikTok 当前页面操作，不凭旧版本路径硬指导。常见入口包括：

```text
Profile
→ Edit profile
→ Change photo / Name / Username
```

每次只修改一项，保存后截图确认。依据：TikTok 帮助中心「Setting up your profile」下的「Edit your profile」「Change your username」条目（https://support.tiktok.com/en/getting-started/setting-up-your-profile ，2026-11-21 核对到条目存在，正文未能读取；具体路径以当前 App 为准）。账号为公开还是私密、个人/创作者/商业账号等设置，要结合目标和官方当前页面判断。

### 发作品

先确认：

- 作品是否完成上传和处理；
- 作品可见范围；
- 是否出现审核、违规或“不适合推荐”等原文提示；
- 账号状态是否有警告；
- 内容是否属于商业推广并需要披露；
- 是否存在版权、重复搬运或其他内容资格问题。

0 播放不能直接归因于 IP。必须先区分上传失败、作品不可见、审核中、推荐不合格、账号受限和统计延迟。TikTok 帮助中心「Account and user safety」下有「Why is my account not being recommended?」和「Your account status」条目（https://support.tiktok.com/en/safety-hc/account-and-user-safety ，2026-11-21 核对到条目，正文需在浏览器里打开看），需要依据时按“深问必查”查当天内容。

### 互动功能

对于不能点赞、关注、收藏：

1. 区分按钮无响应、报错、暂时限制和账号整体限制；
2. 记录 TikTok 原文提示；
3. 检查账号状态、网络连通性和 App 版本；
4. 只做一个低风险测试；
5. 如果平台明确提示限制，优先使用官方申诉或支持入口。依据：TikTok 帮助中心「Creator code of conduct」写明可以通过收到的违规通知申诉，App 里在 Inbox → System notifications → Account updates 找到那条通知；也可以在 App 的“报告问题”页联系 TikTok（https://support.tiktok.com/en/safety-hc/account-and-user-safety/Creator-code-of-conduct ，2026-11-21 核对）。

不要用批量点击、换设备、换 IP 或互刷测试来“验证”限制。

## 故障诊断顺序

1. **平台页面**：原文提示、作品可见性、账号状态；
2. **应用层**：App 版本、权限、缓存、上传状态；
3. **设备层**：系统、时间、存储、相册权限、摄像头和网络权限；
4. **网络层**：Shadowrocket 状态、Proxy 模式、IP 归属、DNS/WebRTC/IPv6；
5. **内容层**：原创性、版权、商业披露、社区规则和推荐资格；
6. **官方处理**：申诉、工单或 TikTok 支持。

每次只修改一个变量。同一问题三轮仍未解决时，整理证据，告知用户联系【船长电商】工作人员。

## 版本和地区提醒

TikTok 的功能入口、可用资格、商业披露要求、推荐资格和申诉路径可能因版本、国家/地区、账号类型和时间不同而变化。涉及这些内容时，回答必须带查询日期，必要时重新查询，不能沿用未经核验的旧 SOP。上面“课程做法”是飞书课程的做法，照着带；用户问门槛、资格或申诉的官方依据时，仍按“深问必查”查当天资料，查到和飞书不一致的，两种说法都告诉用户，不自己改课程做法。
